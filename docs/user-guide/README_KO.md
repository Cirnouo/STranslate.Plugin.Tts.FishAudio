<a id="installation"></a>
## 설치 및 업데이트

Windows에서 STranslate의 **설정 → 플러그인 → 마켓**을 열고 **Fish Audio TTS**를 찾아 설치합니다.

수동으로 설치하려면 [Releases](https://github.com/Cirnouo/STranslate.Plugin.Tts.FishAudio/releases)에서 `STranslate.Plugin.Tts.FishAudio.spkg`를 받은 뒤 **설정 → 플러그인 → 설치**에서 가져옵니다. 현재 안정 버전 STranslate를 권장합니다. 플러그인은 SDK 1.0.15를 사용하며 검증한 호환성 기준은 STranslate v2.0.10입니다. 일반 설치에 .NET SDK를 따로 준비할 필요는 없으며, SDK는 소스 빌드용입니다.

업데이트 후 저장된 모델, 오디오 형식과 네트워크 설정을 확인하세요. 일반적인 연결 문제 때문에 설정을 삭제할 필요는 없습니다. 버전별 변경은 [변경 기록](../../CHANGELOG.md)을 참고하세요.

<a id="first-setup"></a>
## 초기 설정

1. 플러그인 설정의 **API Key**에 공식 페이지에서 발급한 키를 붙여 넣습니다. 편집은 자동 저장되며 별도 확인은 없습니다. 공백·줄바꿈을 추가하거나 실제 키를 공개하지 마세요.
2. 필요하면 잔액을 새로 고칩니다. 시작할 때 조용히 조회를 시도하며, 결과가 없으면 새로 고침 안내가 표시됩니다. 잔액 요청 및 읽기 중에는 API Key 입력이 잠시 잠깁니다.
3. 보이스를 검색하고 미리 들은 뒤 카드의 체크（**적용**）을 누릅니다. **ID로 지정**의 돋보기로 조회 후 결과를 적용하거나 **즐겨찾기**에서 골라도 됩니다. 지정하지 않으면 임의 보이스를 사용합니다.
4. 모델과 PCM/MP3를 확인한 뒤 STranslate에서 짧은 문장을 읽습니다. 지출이 반드시 0이어야 한다면 먼저 [비용 조건](#playback-and-cost)을 읽으세요. 테스트 호출 자체가 무료 자격 확인을 대신하지는 않습니다.

검색, ID 조회와 미리 듣기는 API Key 없이 가능합니다. 합성 및 잔액 조회에는 사용 가능한 키가 필요합니다. 소문자 16진수 32자리의 기존 키와 `sk-fish-` 뒤에 허용 문자 43개가 붙는 새 키를 지원합니다. 로컬 형식 검사가 통과해도 계정 인증이나 잔액이 보장되지는 않습니다.

키가 없으면 보이스 목록과 상세 조회에 `dummy`를 사용합니다. 설정 후에는 입력한 키를 사용하며 즐겨찾기 로드, 시작 시 보이스 갱신, 미리 듣기 링크 갱신에도 적용됩니다. 키가 거부되어도 `dummy`로 재시도하지 않습니다. 미리 듣기 음원과 커버 다운로드에는 키를 보내지 않습니다. 키를 변경하면 이전 조회와 표시용 메타데이터를 지우되 선택한 보이스 ID와 즐겨찾기 ID는 유지합니다. 공유 메모리 메타데이터 캐시는 자격 증명별로 분리되며 다른 키의 항목을 함께 사용하지 않습니다.

화면 언어는 STranslate를 자동으로 따르며 简体中文, 繁體中文, English, 日本語, 한국어를 지원합니다. 플러그인 전용 언어 선택은 없습니다. 화면 언어와 읽을 텍스트의 언어는 독립적이며 모델의 언어 지원은 공식 자료를 확인하세요.

API Key와 ID 입력란의 붙여넣기 아이콘은 오른쪽 안쪽에 있으며 텍스트 공간을 확보합니다. 키는 붙여넣은 뒤에도 자동 저장됩니다. ID 붙여넣기는 입력만 하므로 돋보기나 Enter로 조회한 다음 결과를 별도로 적용하세요.

보이스 ID 입력란은 ASCII 소문자 16진수 문자(`0–9`, `a–f`)를 최대 32자까지 부분 입력할 수 있지만 조회에는 32자 전체가 필요합니다. 잘못된 타이핑 문자는 표시하지 않습니다. Ctrl+V와 입력란 안의 붙여넣기 버튼 모두 잘못된 붙여넣기 전체를 거부하고 기존 입력을 유지합니다. 대문자, 공백, URL, 길이 초과 내용은 받지 않으며 공백 제거, ID 추출, 소문자 변환이나 잘라내기를 하지 않습니다.

<a id="voices"></a>
## 보이스 검색, 선택 및 미리 듣기

탭은 **검색**, **ID로 지정**, **즐겨찾기** 순입니다. 선택한 탭은 마우스를 올리거나 눌러도 강조색을 유지합니다. 선택 카드와 검색·ID·즐겨찾기는 ID로 적용 상태를 동기화합니다. 미적용은 체크, 현재 적용 ID는 X 아이콘을 표시하며 툴팁/접근성 이름은 적용과 지우기입니다. 테두리 없는 동일한 아이콘에 마우스·키보드 포커스 반응을 유지합니다. 같은 ID의 어느 X 아이콘이든 누르면 현재 선택을 해제합니다. 조회·미리 듣기·즐겨찾기는 선택과 독립적입니다.

선택 카드에는 항상 X 아이콘/지우기가 보입니다. 같은 ID의 탐색 카드도 X 아이콘이며 ID 자리표시자만 있어도 해제할 수 있습니다. 미적용 자리표시자의 적용만 유효한 상세를 기다립니다. 적용/해제 설정 저장에 실패하면 이전 선택과 카드 상태를 유지합니다.

ID가 있는 선택 카드, 검색 결과, ID 조회 결과, 즐겨찾기 카드의 제목을 누르면 해당 ID를 클립보드에 복사합니다. 성공하면 떠 있는 알림을, 실패하면 오류를 표시합니다. 작성자 이름과 설명은 일반 텍스트이며 이 복사 동작을 제공하지 않습니다. 복사는 보이스를 적용하거나 미리 듣지 않고 즐겨찾기도 바꾸지 않습니다.

**검색** 탭에 이름을 입력하고 검색 버튼이나 Enter를 누릅니다. 입력만 편집해서는 검색되지 않습니다. 새 검색이 성공하면 결과를 적용하고 1페이지로 돌아갑니다. 미리 듣기는 공개 샘플을 재생하고 체크（**적용**）은 보이스를 선택합니다. 선택 카드와 같은 ID의 탐색 카드는 상태를 공유합니다. 준비 중에는 회전 표시와 취소 사각형, 실제 재생 후에는 진행률이 보입니다. 다운로드·재생 중 다시 누르면 중지되며 다른 보이스로 바꾸어도 이전 미리 듣기가 멈춥니다.

검색 결과는 처음에 펼쳐집니다. 개수 행 오른쪽에 별도 글자 제목 없이 아이콘만 있는 토글이 있어 아래 안내·카드·페이지 탐색을 접습니다. 개수 행은 항상 보입니다. 검색어·결과·페이지·선택은 유지되며 현재 설정 화면에서는 탭 변경과 새 검색 후에도 상태가 남습니다. 번호를 편집했다면 Enter로 확정하거나 원래대로 돌린 뒤 접으세요. 입력란을 벗어나면 번호가 제출될 수 있습니다.

검색·즐겨찾기의 페이지 이동은 테두리 없는 `‹` / `›` 아이콘이며 툴팁과 접근성 이름은 「이전」「다음」입니다. 글자·사각 버튼은 표시하지 않습니다. 번호 입력 후 Enter/포커스 이동도 가능합니다. 검색은 원본 6건에서 비 TTS를 제외합니다. `≈`는 근사 총수, `?`는 미상, `≤`는 접근 상한입니다. 공식 창이 일부만 열면 상한 미상 시 방문한 페이지와 허용된 다음 페이지만 접근하고 실패·빈 페이지는 자동으로 건너뛰지 않습니다.

**ID로 지정**에 소문자 16진수 32자리 ID를 입력하고 돋보기나 Enter로 조회합니다. 미리 듣기·별·선택 아이콘 카드 하나만 불러오며 선택은 바꾸지 않습니다. 미적용이면 체크(**적용**), 적용된 ID면 X 아이콘(**지우기**)로 후자는 선택을 취소합니다. 입력 편집·재조회는 이전 카드를 없애며 페이지 탐색·접기는 없습니다. [공식 커뮤니티](https://fish.audio/app/discovery)의 보이스 “Model ID”는 `s2.1-pro` 같은 엔진과 다릅니다. 선택 카드나 같은 ID의 어느 결과든 X 아이콘으로 임의 보이스로 돌아가며 모델·즐겨찾기·요금 규칙은 유지합니다.

### 즐겨찾기

「즐겨찾기」 탭에는 별 아이콘이 있습니다. 선택/적용한 보이스 카드에도 ID가 있으면 같은 별이 나타나며 검색·ID·즐겨찾기와 공통 ID 목록에 추가/제거하고 상태를 동기화합니다. 등록은 현재 선택을 바꾸지 않으며 임의 보이스에는 저장할 고정 ID가 없습니다.

윤곽선 별은 미등록, 금색 별은 등록 상태이며 검색·ID·즐겨찾기의 같은 ID 카드에 동기화됩니다. 등록과 적용은 독립적이고 해제해도 선택은 지워지지 않습니다. **즐겨찾기**는 ID 탭 오른쪽에 있으며 호스트가 이 플러그인에 제공한 설정 폴더의 `favorite-voices.json`에 순서 있는 ID만 JSON 배열로 저장합니다. 메타데이터는 주 설정에 저장하지 않고 Fish Audio 계정과 동기화하지 않습니다. 재시작해도 ID는 남고 표시 정보는 공유 메모리 캐시에서, 없으면 보이스 상세 조회로 불러옵니다.

기본 목록은 비어 있고 최대 300개입니다. 상한에서는 하나를 먼저 제거해야 하며 자동 퇴출하지 않습니다. 파일 저장이 성공한 뒤 별·목록을 갱신하고 실패하면 기존 상태를 유지합니다. 페이지당 6개이며 정확한 로컬 개수·페이지를 사용합니다. 이전·다음 또는 번호 입력 후 Enter/포커스 이동으로 탐색합니다. 제거 성공 후 즉시 갱신하고 마지막 페이지가 비어도 다른 항목이 남아 있으면 이전 유효 페이지로 이동합니다. 빈 목록은 안내만 표시하며 개수·접기 컨트롤·페이지 탐색은 숨깁니다. 마지막 항목을 지우기 전에 접혀 있었어도 안내는 표시합니다. 저장소 오류는 따로 알립니다. 상세를 못 불러와도 자리표시자와 제거 기능을 유지하며 유효한 정보 전에는 적용할 수 없습니다. 네트워크 오류나 찾을 수 없음으로 저장 ID를 자동 삭제하지 않습니다.

즐겨찾기가 비어 있지 않으면 개수 행 오른쪽에 독립적인 아이콘 전용 토글이 있습니다. 개수는 보이고 안내·카드·페이지 탐색만 접힙니다. 처음에는 펼쳐지며 현재 화면의 탭·목록 변경 후에도 유지하고 검색 쪽에는 영향을 주지 않습니다. 페이지 편집을 먼저 확정하세요. 검색·ID·즐겨찾기·미리 듣기 상세 갱신은 크기가 제한된 메모리 메타데이터 캐시를 공유하며 재시작하면 사라집니다. 오디오 캐시가 아닙니다. 표지 이미지는 기존 공유 영구 캐시를 쓰고 정리해도 ID는 남습니다. 메타데이터 캐시가 적중해도 샘플 URL 만료 검사는 합니다. 페이지 변경, 시작 항목 해제, ID 결과 교체는 미리 듣기를 멈추며 늦은 응답은 이전 항목이나 재생을 복원하지 않습니다.

미리 듣기는 TTS를 호출하지 않습니다. 사용 가능한 샘플 URL은 재사용하므로 매번 상세 정보를 새로 받지 않습니다. 서명 URL은 만료 30초 전부터 갱신하고 서명 시간이 없거나 잘못된 경우도 보수적으로 갱신합니다. 샘플 403/404는 상세 갱신과 재시도를 한 번씩 허용하지만 앞선 만료 갱신도 같은 횟수를 사용합니다. 모든 URL에 서명이 있는 것은 아니며 서명 없는 URL도 영구 보장되지 않습니다. 샘플이 없거나 갱신에 실패해도 대체 음성을 합성하지 않습니다.

검색·ID·즐겨찾기는 호스트의 플러그인 전용 캐시 폴더 내 `cover_images`를 보이스 ID별로 공유합니다. 즐겨찾기용 이미지를 따로 복사하지 않습니다. 로컬 표지를 우선 표시하고 없으면 다시 받아 저장합니다. **캐시 지우기**는 이미지만 삭제하며 별도 설정 폴더의 즐겨찾기 ID 파일이나 공유 메타데이터는 지우지 않습니다. 정리 후 기존 카드는 원래 원격 표지 주소를 사용합니다. 이후 검색, ID 조회 또는 즐겨찾기 페이지 로드 시 표지를 다시 다운로드하고 캐시할 수 있습니다.

재생 간 재사용하는 오디오 캐시는 없습니다. 매번 호스트 HTTP로 샘플을 받아 해당 재생의 메모리 버퍼에 담고 중지·종료·실패 시 해제합니다. 선택 보이스 캐시는 메타데이터와 URL, 표지 캐시는 이미지만 저장합니다. 미리 듣기 진행률은 출력 재생 위치이며 다운로드 진행률이 아닙니다.

공유 메타데이터 캐시는 LRU 방식으로 최대 300개를 보관하고 단조 시계 기준의 클라이언트 TTL은 15분입니다. 같은 앱 안의 플러그인 재초기화에는 공유하지만 앱 재시작 후에는 남지 않습니다. 검색/상세 응답이 갱신하며 즐겨찾기 조작은 TTL을 늘리거나 최신 정보를 덮지 않습니다. 미리 듣기 URL 만료/403/404는 캐시를 우회해 상세를 갱신하고 한 번의 갱신 예산을 유지합니다. 15분은 URL 유효 기간 보장이 아닙니다.

<a id="configuration"></a>
## 설정 안내

편집 항목은 자동 저장됩니다. 아래 기본값은 새 설정 기준이며 이전 형식의 마이그레이션은 뒤에서 설명합니다. 보이스는 음색, 모델은 합성 엔진, API Key는 계정 인증을 결정합니다.

속도, 음량, 표현력(Temperature), 다양성(Top P)은 숫자를 직접 입력할 수 있습니다. 슬라이더 오른쪽 숫자를 누르면 크기가 같은 고정 입력란으로 바뀌며 `dB` 같은 단위는 밖에 남습니다. 포커스를 옮기거나 Enter를 누르면 검사·저장하고 슬라이더에 반영하며 Esc는 편집을 취소합니다. 빈칸, 잘못된 형식, 비유한 값, 범위 밖 입력은 확정된 값으로 복원합니다. 네 항목 모두 소수 둘째 자리까지 표시·저장하며 드래그, 휠, 직접 입력을 0.01 정밀도로 통일합니다. Top P `0.82`와 음량 `1.03 dB` 같은 값도 유지됩니다.

슬라이더 위나 편집 중이 아닌 숫자 텍스트 위에 포인터를 놓고 휠을 돌리면 네 항목 모두 한 단계마다 0.01씩 바뀌며 허용 범위의 끝에서 멈춥니다. 트랙, 손잡이, 숫자 텍스트가 대상이고 옆의 단위는 포함하지 않으며 이때 페이지는 스크롤되지 않습니다. 슬라이더 위에서 휠을 사용하면 드래그할 때와 같은 현재 값 말풍선이 표시되고 잠시 멈추거나 포인터를 옮기면 사라집니다. 숫자 입력란 위의 휠은 값을 바꾸지 않고 페이지를 평소처럼 스크롤합니다.

수치 편집 중에는 ASCII 숫자 `0–9`, 소수 구분 기호 최대 하나와 음량에만 허용되는 맨 앞 마이너스 기호를 받습니다. `.`을 쓸 수 있고 현재 지역 설정이 소수 쉼표를 쓰는 경우에만 `,`도 허용합니다. 속도·표현력·Top P는 최대 4자, 정수 한 자리와 소수 두 자리까지이며 음량은 최대 6자, 정수 두 자리와 소수 두 자리까지입니다(예: `-10.00`). 문자나 자릿수 규칙에 맞지 않는 타이핑은 표시하지 않고 잘못된 붙여넣기는 전체를 거부하여 현재 편집 내용을 유지합니다. 편집 중인 불완전한 입력은 허용하되 수치 범위는 확정할 때 검사합니다.

| 설정 | 기본값 | 범위와 동작 |
|---|---|---|
| API Key | 비어 있음 | 합성·잔액 조회 자격 증명, 붙여 넣기 지원. |
| 보이스 ID | 비어 있음 / 임의 보이스 | 검색·ID·즐겨찾기 카드의 체크（**적용**）으로 선택. 비어 있어도 무료를 뜻하지 않음. |
| 즐겨찾기 | 빈 목록 | 별도 파일에 순서 있는 ID만 저장. 최대 300개, 페이지당 6개, 별로 추가/제거, 동기화 없음. |
| 합성 모델 | 무료 기간 `s2.1-pro-free`, 이후 `s2.1-pro` | 목록과 기본 선택 규칙은 아래 참고. |
| 오디오 형식 | PCM | PCM / MP3. 이전 설정은 보통 MP3 유지. |
| MP3 비트레이트 | 192 kbps | 64 / 128 / 192. PCM이면 항목 전체를 숨기며 MP3로 돌아오면 보존한 값을 표시. |
| 속도 | 1.0 | 0.5–2.0. 드래그·휠·직접 입력 모두 0.01 정밀도. |
| 음량 | 0 dB | -10–+10 dB. 드래그·휠·직접 입력 모두 0.01 정밀도. 합성 음량 오프셋이며 음소거 스위치가 아님. |
| 라우드니스 정규화 | 켜짐 | S2 계열 지원. 허용한 세 모델만 표시/전송하며 다른 모델에서는 값을 보존하고 숨김. |
| 표현력 | 0.7 | 0–1. 드래그·휠·직접 입력 모두 0.01 정밀도. 높을수록 다양한 출력, 낮을수록 일관성. |
| 다양성 | 0.7 | 플러그인 범위 0.05–1. 드래그·휠·직접 입력 모두 0.01 정밀도. Top P 제어. |
| 지연 모드 | 품질 우선 (`normal`) | 품질 우선 / 균형 (`balanced`) / 저지연 (`low`). 첫 단어 시작 시간을 보장하지 않음. |
| 텍스트 정규화 | 꺼짐 | 숫자·단위 등을 읽기 쉬운 텍스트로 변환. |
| 컨텍스트 연동 | 켜짐 | 이번 합성의 앞선 조각을 사용하며 이전 요청의 다른 오디오는 참조하지 않음. |
| 잔액 새로 고침 | 시작 시 조용히 시도 | 수동 조회는 지연 표시, 합성 성공 후 조용히 갱신. 지출 제한이 아님. |
| 표지 캐시 | 자동 | 디스크 용량 표시와 **캐시 지우기**. 보이스 ID/정보/즐겨찾기 유지. |
| 무료 모델 안내 카드 | 닫지 않음 | 클릭하면 무료 모델 선택, 닫으면 숨김 기억. 이용 자격은 바꾸지 않음. |
| 화면 언어 | 호스트를 따름 | 다섯 언어 자동 전환, 별도 선택 없음. |

라우드니스 정규화는 `s2.1-pro-free`, `s2.1-pro`, `s2-pro`에서만 표시하고 `normalize_loudness`를 보냅니다. S1에서는 효과가 없고 Drama 3는 지원 미확인이라 현재 클라이언트 기능 정책으로 숨깁니다. Drama 3 서버 비호환이 입증되었다는 뜻은 아닙니다. 숨겨도 값을 보존하고 요청 필드는 생략하며 허용 모델로 돌아오면 복원합니다.

**2026-12-01T00:00:00Z 이전** 목록은 `s2.1-pro-free`, `drama-3`, `s2.1-pro`, `s2-pro`, `s1` 순이며 기본값은 무료 모델입니다. 이후 무료 항목을 숨기고 Drama 3가 목록 첫 항목이 되지만 기본값은 `s2.1-pro`입니다. 목록 순서와 기본 선택은 독립적입니다. 유효한 저장 선택은 재정렬로 바뀌지 않고, 사용할 수 없는 선택은 현재 기본값으로 정규화합니다. 프로모션은 [공식 조건](https://fish.audio/blog/s2-1-pro-free-api/)을 따릅니다.

S1은 현재 선택 가능합니다. [공식 WS 문서](https://docs.fish.audio/api-reference/endpoint/websocket/tts-live)는 2026-12-31 종료 및 이후 S1 요청의 S2.1-Pro 제공을 안내합니다. 해당 날짜가 가까워지면 요금과 플러그인 업데이트를 확인하세요. 예전 선택이 영구적으로 같은 서비스를 뜻하지 않습니다.

주 설정은 SchemaVersion=2입니다. 이전 유효 값을 유지하고 버전 없음/1의 누락·잘못된 형식은 MP3로 이전하며 유효 비트레이트를 보존합니다. 새 설정은 PCM입니다. 즐겨찾기 ID는 별도 파일이며 주 설정의 메타데이터 필드나 새 스키마가 아닙니다. 형식 전환은 다른 값과 숨겨진 MP3 값을 유지하고 모델 전환도 숨겨진 라우드니스 값을 보존합니다. 설정을 불러올 때 범위 밖 숫자는 기본값으로 돌아가고 유효 값은 슬라이더 간격이 아닌 표시 소수 자릿수로 반올림합니다. 미래/중복 버전은 주 설정을 보호하므로 저장을 강제하려고 버전을 낮추지 마세요.

기존 스트리밍 프록시 모드/주소는 더 이상 적용되지 않으며 정상적인 정규 저장 시 제거됩니다. 스키마는 2를 유지합니다.

Top P의 0.05 하한은 플러그인 호환 정책이지 공식 API 최솟값 주장이 아닙니다. 저장된 0은 0.05가 되고 음수·비유한 값·1 초과는 기본 0.7로 복구합니다. 표현력(Temperature)의 0은 여전히 유효하고 범위는 0–1입니다.

<a id="audio-formats"></a>
## PCM과 MP3

PCM은 44.1 kHz, 16비트, 모노이며 압축 디코딩이 없지만 초당 약 88,200바이트입니다. MP3는 연속 디코딩을 사용하고 64/128/192 kbps로 전송량을 줄입니다. 비트레이트가 높으면 대역폭도 늘어납니다. 느린 연결에는 MP3를, 압축 처리를 피하려면 PCM을 시도하세요. 서버 대기, 네트워크, 장치 버퍼와 초기 무음도 영향을 주므로 형식만으로 첫 단어 시작 시간을 보장할 수 없습니다.

긴 텍스트는 필요에 따라 나누어 보내면서 음성을 받아 재생합니다. 일반 텍스트는 전체 합성을 기다리지 않고 시작할 수 있으나 복잡하거나 닫히지 않은 감정·음소 표시는 안전한 구분을 늦출 수 있습니다. 입력 순서는 유지하지만 완전한 마크업 편집기는 아닙니다. 모델별 감정·발음·화자 문법은 [공식 문서](https://docs.fish.audio)를 참고하세요. WAV/Opus 선택은 제공하지 않습니다.

<a id="network-and-proxy"></a>
## 네트워크 및 시스템 연결

정식 읽기는 네이티브 WebSocket을 사용하며 항상 시스템 기본 프록시를 따릅니다. 플러그인에 별도 프록시 스위치, 모드나 주소 설정은 없습니다. 보이스 검색·상세, 잔액과 미리 듣기 샘플은 STranslate 호스트 HTTP 설정을 유지합니다. HTTP 성공만으로 WebSocket 연결이 확인되지는 않습니다.

검색만 성공하면 Windows 시스템 네트워크/프록시, 시스템 프록시 서비스와 WebSocket 방화벽 허용 여부, 모델 가용성과 계정 권한을 확인하세요. 플러그인 안에서 프록시 입력란을 찾을 필요는 없습니다. 연결을 고친 후 수동으로 재시도하며 자동 모델 변경이나 재합성은 하지 않습니다.

<a id="playback-and-cost"></a>
## 읽기, 중지와 비용

STranslate의 읽기 기능으로 사용합니다. 새 읽기는 이전 세션을 취소하고 출력 정리를 기다립니다. 호스트 중지, 초기화 세대 종료와 앱 닫기도 해당 재생을 취소합니다. 실행 중 요청은 시작할 때 설정을 사용하고 이후 편집은 다음 읽기에 적용합니다. 정상 완료는 받은 실제 음성 재생이 끝날 때까지 기다립니다.

취소는 클라이언트 중지이며 서버가 생성하거나 청구하지 않았다는 보장이 아닙니다. 연결 끊김, 시간 초과나 디코딩 오류는 자동 재합성이나 유료 모델/HTTP/다른 전송으로의 전환을 일으키지 않습니다. 다만 만료 모델의 시작 시 정규화는 현재 기본값을 선택할 수 있으므로 업데이트나 프로모션 종료 후 다시 확인하세요.

지출이 엄격히 0이어야 한다면 현재 공식 조건에서 자격을 확인하고 `s2.1-pro-free`를 명시적으로 선택한 경우만 합성하세요. 확인할 수 없으면 검색과 미리 듣기까지만 사용하세요. 임의 보이스, 키 형식, 그대로인 잔액이나 이름의 free만으로는 무료를 입증할 수 없습니다. 유료 모델에는 잔액이 필요하고 차감은 늦을 수 있으며 플러그인에 지출 하드 한도는 없습니다. 무료 서비스의 첫 오디오 지연도 보장되지 않습니다.

<a id="troubleshooting"></a>
## 문제 해결

| 현상 | 확인 및 조치 |
|---|---|
| 라우드니스 안 보임 / 기존 Top P가 0.05 | 클라이언트 허용 모델에 따라 숨기되 값은 보존합니다. Top P의 0만 호환 하한으로 올라가고 Temperature 0은 유효합니다. |
| 키 형식 오류 | 공식에서 다시 복사하고 공백·줄바꿈 제거. 보이스 ID와 혼동하지 마세요. |
| 검색 성공, 합성 실패 | 호스트 HTTP와 시스템 WebSocket 경로, 모델 가용성 및 계정 권한을 각각 확인. |
| 총수는 큰데 다음 페이지 없음 | 공식 검색 창 제한일 수 있으므로 더 구체적인 이름으로 검색. |
| 접은 뒤 카드가 안 보임 | 다시 펼치세요. 검색어·페이지·선택은 유지됩니다. |
| ID 조회 후 선택이 그대로임 | 결과 카드의 체크（**적용**）을 누르세요. 조회·미리 듣기·별은 자동 적용하지 않습니다. |
| 추가 불가/자리표시자만 보임 | 300개 상한, 파일 저장 안내와 보이스 상세 연결 확인. 조회 실패에도 ID는 남고 제거할 수 있습니다. |
| 미리 듣기 실패/샘플 없음 | 호스트 연결 확인. 만료되면 상세 재조회. TTS로 대체하지 않습니다. |
| 첫 재생이 느림 | 시스템 연결·장치를 확인하고 PCM/MP3 비교. 무료 대기의 영향은 남습니다. |
| 무음/중단 | Windows 출력, 시스템·앱 음량과 장치 연결을 확인하고 수동 재시도. |
| 잔액이 안 바뀜 | 기다린 후 새로 고침. 예전 잔액은 무료 증거가 아닙니다. |
| 정리 후 표지 재로딩 | 정상입니다. 이미지 파일만 지우고 보이스 설정·즐겨찾기는 남깁니다. |

해결되지 않으면 [Issues](https://github.com/Cirnouo/STranslate.Plugin.Tts.FishAudio/issues)에 플러그인/호스트/Windows 버전, 재현 단계, 모델/형식 및 시스템 네트워크 상태와 민감 정보를 뺀 오류를 적어 주세요. API Key, 전체 서명 URL, 프록시 암호나 개인 텍스트는 올리지 마세요. 개발은 [CONTRIBUTING](../../CONTRIBUTING.md)을 참고하세요.
