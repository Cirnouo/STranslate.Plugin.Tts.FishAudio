<a id="installation"></a>
## 安装与更新

在 Windows 上使用 STranslate。推荐进入 **设置 → 插件 → 市场**，搜索 **Fish Audio TTS** 并下载安装。

手动安装时，从 [Releases](https://github.com/Cirnouo/STranslate.Plugin.Tts.FishAudio/releases) 下载 `STranslate.Plugin.Tts.FishAudio.spkg`，在 STranslate 的 **设置 → 插件 → 安装** 中导入。优先使用当前稳定版 STranslate；当前插件适配 SDK 1.0.15，兼容验证基线为 STranslate v2.0.10。普通安装无需自行配置 .NET SDK；SDK 仅用于从源码构建。

更新时安装新包并检查已保存的模型、音频格式和网络设置。不要用删除配置的方式排查普通联网问题。版本变化见[更新日志](../../CHANGELOG.md)。

<a id="first-setup"></a>
## 初次配置

1. 打开 Fish Audio TTS 的插件设置，将官方页面创建的 API Key 粘贴到 **API Key**。输入会自动保存，无需额外确认。不要添加空格或换行，也不要公开真实密钥。
2. 需要时点击余额刷新。启动时会静默尝试加载余额；尚未加载时显示“点击刷新”。余额请求与朗读期间会临时锁定 API Key 输入，结束后恢复。
3. 搜索并试听声音，点击卡片上的勾号（**应用**）；或在 **通过 ID** 中粘贴 ID，点击放大镜查询后再点击结果卡片的勾号（**应用**）。也可从 **收藏夹** 选用，或保留随机声音。
4. 核对合成模型，选择 PCM 或 MP3，再在 STranslate 中朗读一小段文本。若必须零费用，先阅读[费用约束](#playback-and-cost)，不要以一次测试代替核实免费资格。

搜索、通过 ID 查询和试听不要求 API Key；合成与余额查询需要有效密钥。插件兼容旧版 32 位小写十六进制 Key，以及 `sk-fish-` 后接 43 位合法字符的新版 Key。本地格式通过只表示输入形状正确，不代表账号认证或余额充足。

未配置 Key 时，声音列表与详情查询使用 `dummy`；配置后使用填写的 Key，包括收藏夹加载、启动声音刷新与试听链接刷新。Key 被拒绝时不会改用 `dummy` 重试。试听音频与封面下载不携带 Key。更换 Key 会取消旧查询，保留已显示的搜索、ID 结果、收藏及已选声音信息；后续查询使用新 Key。共享内存元数据按凭据隔离，不同 Key 的记录不会混用。

界面自动跟随 STranslate 的语言设置，支持简体中文、繁體中文、English、日本語、한국어。插件没有单独的语言选择项。朗读文本的语言与界面语言是不同概念，模型语言支持请查官方说明。

API Key 与通过 ID 的输入框都把粘贴图标放在框内右侧，并预留文字空间。API Key 粘贴后照常自动保存；ID 粘贴只填入内容，需要再点击放大镜查询或按 Enter，不会直接应用声音。

声音 ID 输入框允许逐步输入最多 32 个 ASCII 小写十六进制字符（`0–9`、`a–f`），查询仍须完整 32 位。无效的键入字符不会显示。Ctrl+V 与框内粘贴按钮都会整次拒绝无效粘贴并保留原输入；大写字母、空白、URL 或超长内容均不接受，不会自动去空白、提取 ID、转为小写或截断。

<a id="voices"></a>
## 搜索、选择与试听声音

三个浏览入口依次为 **搜索**、**通过 ID**、**收藏夹**，每次显示一个面板。当前标签在悬停或按下时仍保留强调色，便于识别所在面板。已选声音及搜索、ID、收藏卡片的应用状态按声音 ID 同步：未应用时显示勾号，当前已应用 ID 显示叉号。勾号的提示/无障碍名称为“应用”，叉号为“清除”，是统一的无边框图标操作，保留悬停与键盘焦点反馈。点击任意匹配卡片的叉号都会取消当前声音。查询、试听与星标收藏独立，不会自动应用或取消选择。

已选声音卡片有选择时始终显示叉号；搜索、ID、收藏中与当前 ID 匹配的卡片也显示叉号。即使匹配卡片还只是 ID 占位，也可用叉号清除选择；只有未应用项的勾号需要等待有效详情。应用或清除的设置保存失败时，原选择与卡片状态保留。

有声音 ID 的已选声音、搜索结果、通过 ID 结果与收藏夹卡片，都可点击标题将该 ID 复制到剪贴板。复制成功后显示浮动提示，失败则显示错误提示；作者与描述仍是普通文字，不提供此复制操作。复制不会应用、试听或改变收藏。

在 **搜索** 标签页输入名称，点击搜索按钮或按 Enter。修改输入框不会立即查询；提交成功后才应用新查询并回到第一页。结果中的试听按钮播放声音附带的公开样本，点击勾号（**应用**）使用音色。已选卡片与相同 ID 的浏览卡片共享试听状态；准备期间显示旋转等待与取消方块，实际播放后显示进度。下载或播放期间再次点击可以停止，切换声音也会停止旧试听。

搜索结果首次显示时展开。结果数量行右侧只有展开/收起图标，没有单独的文字标题；点击图标切换下方的提示、卡片与分页，数量行始终可见。收起不会清空查询、结果、页码或已选声音；切换标签或发起下一次搜索也保留当前设置视图中的展开状态。若正在编辑页码，先按 Enter 提交或还原输入，再收起列表，避免失焦触发页码提交。

搜索与收藏分页使用无边框 `‹` / `›` 图标，提示/无障碍名称分别为“上一页”“下一页”，含悬停提示与键盘可访问名称，不显示文字或矩形按钮。也可输入页码后按 Enter 或离开输入框提交。搜索每页请求六条原始记录，非 TTS 声音会被过滤。`≈` 是近似总数，`?` 是未知，`≤` 是可访问页数上界。官方窗口可能只开放部分结果；未知上界时只能访问已到达页和允许的下一页，不自动跳过失败或空页。

在 **通过 ID** 输入完整的 32 位小写十六进制声音 ID，点击放大镜或按 Enter 查询。它只加载一张带试听、星标与应用状态图标的卡片，不改变选择。未应用时点击勾号（**应用**）切换声音；若 ID 已应用则显示叉号（**清除**），点击会取消选择。修改 ID 或重新查询移除旧结果；没有分页或折叠。可从[官方声音社区](https://fish.audio/app/discovery)取得 ID；网站“模型 ID”是声音资产 ID，不是 `s2.1-pro` 等引擎名。已选卡片或任何匹配结果的叉号都能恢复随机声音，保留模型、收藏及费用规则。

### 收藏夹

“收藏夹”标签带有星标图标。已选声音卡片在有声音 ID 时也显示同样的收藏星标，可直接添加或取消收藏；它与搜索、通过 ID、收藏列表共用同一份 ID 集合，状态同步。收藏或取消收藏不改变当前选择，随机声音没有可收藏的固定 ID。

卡片上的空心五角星表示未收藏，金色实心星表示已收藏；点击切换，搜索、通过 ID 与收藏列表中相同声音的星标同步。收藏与应用互相独立，取消收藏不会清除已选声音。**收藏夹** 位于 **通过 ID** 右侧，仅将声音 ID 按顺序存为 JSON 数组，保存到宿主为本插件提供的设置目录中的 `favorite-voices.json`，不将收藏元数据写进主设置，也不与 Fish Audio 账号同步。重启后收藏 ID 仍保留，展示信息从共享内存缓存取得，未命中时通过声音详情查询加载。

收藏默认空列表，最多 300 个。达到上限会提示，须先取消一个再添加，不会自动淘汰旧收藏。文件保存成功后才更新星标与列表；保存失败时保留原状态。每页六个，数量及页数按本地实际收藏计算；可用前后按钮或输入页码后按 Enter／离开输入框。取消收藏成功保存后立即移除并更新数量；最后一页被删空但仍有收藏时回到上一有效页。收藏夹为空时只显示空列表提示，不显示结果数量、折叠图标或分页；即使删除最后一项前处于收起状态，提示也会显示。存储错误另行提示。详情尚未加载时保留占位卡片与取消收藏入口，获得有效详情前不能应用；网络错误或声音未找到不会自动删除收藏 ID。

收藏夹非空时，数量行右侧有独立的展开/收起图标；收起后数量仍可见，仅提示、卡片与分页隐藏。首次展开，状态在当前设置视图中保留，切换标签或更新列表不重置，也不影响搜索区。若编辑页码，先提交或还原后再收起。搜索、ID 查询、收藏与试听详情刷新共享有界的内存元数据缓存；它不跨重启保存，也不是音频缓存。封面图片沿用共享的持久缓存，清理封面不会删除收藏 ID。样本 URL 仍按下文到期规则检查，不能因为元数据命中缓存就跳过。切换收藏页、取消发起试听的收藏或替换 ID 结果，会停止该卡片的试听；迟到结果不会重新添加收藏或恢复旧播放。

试听不调用 TTS。样本链接尚可用时复用 URL，无需每次刷新详情；签名链接进入到期前 30 秒窗口时会刷新，签名时间缺失或无效时也会保守刷新。资源返回 403/404 时最多刷新详情并重试一次；先前已因到期刷新则不再额外刷新。不是所有 URL 都带签名，不能假定无签名链接永久有效。最新详情没有样本或刷新失败时不会合成替代音频。

搜索、通过 ID 与收藏声音共用原有的本地封面图片缓存，按声音 ID 复用宿主为本插件提供的缓存目录中的 `cover_images` 文件；收藏不会复制另一份图片。命中优先显示本地封面，未命中则重新加载并缓存。**清理缓存** 只删除这些封面，不删除独立设置目录中的收藏 ID 文件，也不清空共享声音元数据；清理后，现有卡片改用原始远程封面地址；后续搜索、通过 ID 查询或加载收藏页时，可再次下载并缓存封面。

插件没有可跨次复用的音频缓存：每次试听都通过宿主 HTTP 获取样本，放入本次内存缓冲，停止、结束或失败后释放。已选声音缓存只保存元数据与样本 URL；封面缓存只存图片。试听进度表示输出播放位置，不是下载进度。

共享元数据缓存最多保存 300 个最近使用条目，客户端有效期为 15 分钟，按单调时钟计算；它可跨插件重初始化共享，但应用重启后不保留。搜索及详情响应更新缓存，收藏操作本身不延长有效期或覆盖较新的信息。样本 URL 到期或返回 403/404 时会绕过元数据缓存刷新，仍沿用一次刷新预算；15 分钟不是样本 URL 的有效期保证。

<a id="configuration"></a>
## 配置说明

编辑项自动保存。以下默认值适用于新配置，旧配置的格式迁移见后文。模型、声音、API Key 是三个独立选择：声音决定音色，模型决定合成引擎，API Key 用于账号认证。

语速、音量、表现力（Temperature）与多样性（Top P）都可直接输入数值：点击滑块右侧的数字，会切换成固定大小的输入框，`dB` 等单位留在框外。离开输入框或按 Enter 时会校验并保存，滑块同步更新；按 Esc 取消编辑并恢复原值。空白、格式无效、非有限值或超出范围的输入会恢复编辑前的值。四项配置统一显示并保存两位小数，拖动滑条、滚轮和直接输入都使用 0.01 精度，例如 Top P 的 `0.82` 和音量 `1.03 dB` 都会保留。

将指针停在滑条上，或停在尚未点击进入编辑的数值文字上，滚动滚轮即可按每格 0.01 微调，到允许的上下限后停止。滑条轨道、滑块和数值文字接收此操作，旁边的单位不在目标范围内；此时滚轮不会滚动设置页。在滑条上使用滚轮时，会显示与拖动时相同的当前数值气泡，停止调整片刻或移开指针后消失。点击进入数值输入框后，在输入框上滚动不会调值，设置页按通常方式滚动。

数值编辑只接受 ASCII 数字 `0–9`、最多一个小数分隔符，以及仅音量允许的开头负号。可以使用 `.`；当前区域使用小数逗号时也接受 `,`。语速、表现力、Top P 最多 4 个字符、整数一位和小数两位；音量最多 6 个字符、整数两位和小数两位（如 `-10.00`）。不合规则的键入不会显示，无效粘贴整体拒绝并保留当前草稿。允许尚未完成的编辑草稿，范围在确认时检查。

| 配置 | 默认值 | 可选值与作用 |
|---|---|---|
| API Key | 空 | 合成与余额查询凭据；可粘贴。 |
| 声音 ID | 空，随机声音 | 搜索、ID 查询或收藏卡片上点击 勾号（**应用**）；空值不代表免费。 |
| 收藏夹 | 空列表 | 独立文件仅保存有序 ID，最多 300 个；星标添加/取消，每页六个，不同步账号。 |
| 合成模型 | 免费期内 `s2.1-pro-free`，之后 `s2.1-pro` | 支持列表与默认策略见下文。 |
| 音频格式 | PCM | PCM / MP3；旧配置通常保留 MP3。 |
| MP3 比特率 | 192 kbps | 64 / 128 / 192；PCM 下隐藏整项，切回 MP3 恢复显示并保留数值。 |
| 语速 | 1.0 | 0.5–2.0；拖动、滚轮和直接输入均为 0.01 精度。 |
| 音量 | 0 dB | -10–+10 dB；拖动、滚轮和直接输入均为 0.01 精度；这是合成音量偏移，不是静音开关。 |
| 响度归一化 | 开启 | 支持 S2 系列模型；仅三项白名单显示并发送，其他模型隐藏但保留值。 |
| 表现力 | 0.7 | 0–1；拖动、滚轮和直接输入均为 0.01 精度；越高越多样化，越低一致性越强。 |
| 多样性 | 0.7 | 插件允许 0.05–1；拖动、滚轮和直接输入均为 0.01 精度；控制 Top P 采样。 |
| 延迟模式 | 质量优先（`normal`） | 质量优先 / 平衡（`balanced`）/ 低延迟（`low`）；不保证固定首字延迟。 |
| 文本规范化 | 关闭 | 将数字、单位符号等转成更适合朗读的文本。 |
| 上下文关联 | 开启 | 使用本次合成中的前序片段保持一致性，不读取此前生成的其他音频。 |
| 余额刷新 | 启动静默尝试 | 手动刷新显示延迟；朗读成功后静默刷新。不是额度限额设置。 |
| 封面缓存 | 自动使用 | 显示磁盘占用，提供 **清理缓存**；保留声音 ID、元数据与收藏。 |
| 免费推广卡 | 未关闭 | 点击选择免费模型，关闭后记住隐藏状态；不改变账号资格。 |
| 界面语言 | 跟随宿主 | 五种语言自动切换，无单独插件语言项。 |

响度归一化仅对 `s2.1-pro-free`、`s2.1-pro`、`s2-pro` 显示并发送 `normalize_loudness`。S1 下该参数不生效；Drama 3 的支持尚未确认，当前客户端能力策略将其隐藏，不代表已证实服务端不支持。隐藏时保留原值并省略请求字段，切回白名单模型后恢复。

截至当前插件策略，**2026-12-01T00:00:00Z 之前**依次列出 `s2.1-pro-free`、`drama-3`、`s2.1-pro`、`s2-pro`、`s1`，默认免费模型；之后隐藏免费项，依次列出其余四项，但默认仍是 `s2.1-pro`。列表第一项不等于默认项。已保存的有效选择不会因为重排而变化；失效选择会按当时默认策略规范化。免费活动以[官方条件](https://fish.audio/blog/s2-1-pro-free-api/)为准。

S1 仍在当前选择列表中；[官方说明](https://docs.fish.audio/api-reference/endpoint/websocket/tts-live)已公告其于 2026-12-31 退役，随后指定 S1 的请求将由 S2.1-Pro 提供。临近该日期请核对官方计费及插件更新，不能假定旧模型选择永远保持原服务。

主配置版本为 SchemaVersion=2。升级保留有效字段；无版本与版本 1 配置迁移时，缺失或无效音频格式回落 MP3，并保留有效比特率，新配置默认 PCM。收藏 ID 使用独立文件，不是主配置中的元数据字段，也不新增配置版本。切换格式不清空其他参数，隐藏的 MP3 比特率仍保留；切换模型不清空隐藏中的响度值。加载配置时，无效范围值恢复默认；有效数值按显示小数位数保留，不按滑块步进对齐。未来版本或重复版本标记会保护主配置，避免覆盖宿主文件；不要手动降低版本强制保存。

旧版流式代理模式与地址不再生效；受支持配置的规范化保存会移除这些旧字段，版本仍为 2。

Top P 的 0.05 下限是插件的兼容策略，不是对官方 API 最小值的声明：旧配置中的 0 提升到 0.05；负值、非有限值或大于 1 的值恢复默认 0.7。表现力（Temperature）的 0 仍合法，其范围继续为 0–1。

<a id="audio-formats"></a>
## PCM 与 MP3

PCM 使用 44.1 kHz、16 位、单声道，避免压缩解码，数据约为每秒 88,200 字节。MP3 使用持续解码，64/128/192 kbps 可降低网络传输量；数值越高，带宽需求越大。较慢网络可尝试 MP3，追求较少压缩处理可用 PCM。端到端速度也受服务器排队、网络、设备缓冲和初始静音影响，任何格式都不保证固定首字时间。

长文本按需分段传送，音频接收与播放并行，不等待整段音频下载。普通文本首段可先开始播放；复杂或未闭合的情绪/发音标记可能延迟安全分段。插件保留文本顺序，不提供完整标记编辑器；模型支持的情绪、发音与说话人语法请查[官方文档](https://docs.fish.audio)。目前不提供 WAV/Opus 选择。

<a id="network-and-proxy"></a>
## 网络与系统连接

正式朗读使用原生 WebSocket，并始终采用系统默认代理；插件没有独立的代理开关、模式或地址设置。声音搜索、详情、余额和试听样本继续使用 STranslate 宿主 HTTP 网络设置，两个路径需要分别可用。宿主 HTTP 可用，不代表系统 WebSocket 路径已经连通。

大陆网络无法访问 `fish.audio` 服务时，请检查 Windows 系统网络/代理、代理程序是否可用，以及防火墙是否允许 WebSocket；不要在插件中寻找代理输入项。搜索可用但朗读失败时，同时核对系统连接、模型可用性和账号权限。网络恢复后手动重试；插件不会自动换模型或发起第二次合成。

<a id="playback-and-cost"></a>
## 朗读、停止与费用

在 STranslate 的朗读功能中使用本插件。新的朗读会取消旧会话并等待旧输出清理；宿主停止、重初始化或关闭也会取消所属播放。运行中的朗读使用启动时的设置快照，稍后的设置修改应用于下一次朗读。正常结束会等到已接收的真实音频播放完毕。

取消只表示客户端停止，不保证服务端未生成内容或未计费。插件不会因断线、超时或解码错误自动发起第二次合成，也不会在会话失败后自动换付费模型、HTTP 或其他传输。到期模型的启动规范化会改用当时默认项，因此更新或到期后仍需重新核对模型。

若必须严格零费用，仅在当前官方条件确认允许、且明确选择 `s2.1-pro-free` 时合成。无法确认时停在搜索与试听，不执行真实合成。随机声音、Key 格式正确、未扣余额或名称含 free 都不能单独证明免费。付费模型需要相应余额；余额扣除可能延迟，插件没有消费硬限额。免费服务也没有固定首音延迟保证。

<a id="troubleshooting"></a>
## 常见问题排查

| 现象 | 检查与处理 |
|---|---|
| 响度项不见或旧 Top P 变为 0.05 | 响度项按客户端模型白名单隐藏，值仍保留；Top P 的旧 0 按兼容下限提升，Temperature 的 0 不变。 |
| API Key 格式提示 | 从官方页面重新复制，去掉首尾空白/换行；Key 与声音 ID 不可混用。 |
| 搜索可用，朗读失败 | 分别检查宿主 HTTP 与系统 WebSocket 网络、模型可用性及账号权限。 |
| 没有更多页但总数很大 | 可能受官方访问窗口限制；尝试更精确名称，不按报告总量推算可跳页。 |
| 收起后找不到卡片 | 再次展开搜索结果；收起保留查询、页码与选择，不必重新搜索。 |
| ID 查到声音但未改变选择 | 点击结果卡片的勾号（**应用**）；确认查询、试听或星标都不会自动应用。 |
| 无法新增收藏或仅显示占位 | 检查 300 个上限、文件保存提示与声音详情网络；加载失败不删除 ID，可取消收藏后重试。 |
| 试听不可用或失败 | 检查宿主网络；声音可能无样本或 URL 已失效，可重新查询详情。不会以 TTS 代替试听。 |
| 首次播放等待较久 | 检查系统网络与输出设备，可比较 PCM/MP3；免费队列和模型生成仍会影响速度。 |
| 播放无声或中断 | 检查 Windows 输出设备、系统/应用音量与设备连接；修正后手动重试。 |
| 余额未立即变化 | 等候后手动刷新；旧余额不是免费证据。 |
| 清理缓存后封面重载 | 这是正常行为；清理仅删除图片，不会删除声音设置或收藏。 |

仍有问题时，在 [Issues](https://github.com/Cirnouo/STranslate.Plugin.Tts.FishAudio/issues) 提供插件/宿主版本、Windows 版本、复现步骤、模型/格式及系统网络情况与已脱敏错误。不要上传 API Key、完整签名 URL、代理密码或私人朗读文本。开发与贡献请见 [CONTRIBUTING](../../CONTRIBUTING.md)。
