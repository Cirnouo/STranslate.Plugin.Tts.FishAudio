## 1. 开始使用

<a id="installation"></a>
### 安装

在 Windows 的 STranslate 中打开 **设置 → 插件 → 市场**，搜索 **Fish Audio TTS** 并安装。

**网络前提**：大陆网络无法访问 `fish.audio` 服务。请先完成本页[网络检查](#network-and-proxy)，再配置和朗读。

<a id="first-setup"></a>
### 完成第一次朗读

搜索、ID 查询和公开样本试听可不填 Key，但仍需联网。正式朗读与余额查询需要有效的 Fish Audio API Key。

1. 在[官方 API Key 页面](https://fish.audio/app/api-keys)创建 Key，粘贴到插件的 **API Key**，自动保存。不要附加空白或换行，也不要公开密钥。
2. 在 **搜索** 找到声音，试听后点击 **应用**；也可不选声音，使用随机音色。
3. 选择合成模型并核对[费用条件](#playback-and-cost)。必须零费用时，先确认官方资格，再明确选用 `s2.1-pro-free`，然后才开始任何测试朗读。
4. 回到 STranslate，选用 **Fish Audio TTS** 执行一小段文本的朗读。

### 可选：余额、手动安装与更新

需要查看余额时，点击余额刷新即可。

手动安装可从 [Releases](https://github.com/Cirnouo/STranslate.Plugin.Tts.FishAudio/releases) 下载 `STranslate.Plugin.Tts.FishAudio.spkg`，再从 **设置 → 插件 → 安装** 导入。

推荐使用稳定版 STranslate，已验证兼容基线为 v2.0.10。更新后检查保存的模型、格式和网络设置，版本变化见[更新日志](../../CHANGELOG.md)。

界面跟随宿主，支持简体中文、繁體中文、English、日本語、한국어、Русский、Türkçe，无独立语言选项。界面语言与模型可朗读的语言不同，后者见[官方文档](https://docs.fish.audio)。

## 2. 选择与管理声音

<a id="voices"></a>
### 从三个入口找声音

声音决定音色，模型决定合成引擎。社区声音的“模型 ID”是声音资产 ID，不是 `s2.1-pro` 等引擎名。

| 入口 | 操作 |
|---|---|
| **搜索** | 输入名称，点击搜索或按 Enter。 |
| **通过 ID** | 从[官方声音社区](https://fish.audio/app/discovery)或卡片标题复制 ID，只粘贴 ID 本身而非网址。点击放大镜或按 Enter 查询，再点击结果的 **应用**。 |
| **收藏夹** | 打开本机保存的声音，详情载入后试听或应用。 |

| 想做什么 | 操作 |
|---|---|
| 听样本 | 点击播放，再点一次停止。试听使用现成公开样本，不会应用声音或合成你的文本。 |
| 用于朗读 | 点击勾号 **应用**。要恢复随机声音，点击叉号 **清除**；模型与收藏保留。随机声音不代表免费。 |
| 留待以后使用 | 点击星标添加或取消收藏；取消收藏不会清除当前使用的声音。随机声音没有可收藏的固定 ID。 |
| 复制声音 ID | 点击卡片的 **标题**，不是作者或描述。 |

点击搜索框内的**搜索选项**，选择**全部语言**，或点击语言方块多选。全部语言与具体语言互斥，取消最后一种具体语言会恢复全部；选满十种预设仍是限定这些语言。多种语言如何组合由 Fish Audio 决定。排序可选**相关优先**、**热门优先**或**最新优先**。点击**应用**会关闭选项，并立即用当前搜索文字刷新第一页，即使选项没有变化也会刷新。**重置**只将待应用选项恢复为全部语言和相关优先；**关闭**会放弃修改。搜索或回车沿用已应用选项，翻页沿用上次成功的搜索。选项仅在本次设置会话中保留；刷新失败会保留原有结果和选项。

搜索、通过 ID、收藏夹和已选声音使用相同的语言标签，在独立单行中显示旗帜与当前界面语言的名称。卡片越宽，可显示的标签越多，没有固定三个的上限；点击 `+N` 可在弹窗中查看恰好剩余的 N 种语言。名称始终保留，仅当第一个标签的完整名称也放不下时用省略号缩短，悬停可查看全名。缺少语言元数据时隐藏整行。标签来自 Fish Audio 的声音元数据，不是固定的合成语言白名单、说话者国籍或引擎完整语言能力说明；无法识别的语言代码保留原文字并显示通用图标。

卡片右下角显示按系统本地时区换算的创建日期（`yyyy-MM-dd`），悬停可查看包含时区偏移的完整时间；缺少或无效时显示 `—`。没有描述时整行自动收起，语言、作者和热度随之上移。

收藏保存在本机，重启后保留，不与 Fish Audio 账号同步。最多 300 个，达到上限先移除一个。详情与试听仍需联网，查询失败不会删除已保存的收藏。

搜索和收藏可用 `‹` / `›` 翻页，页码框仅接受数字，超过当前可访问最大页码时会立即调回上限。输入新页码后离开输入框即可跳转，也可按 Enter；页码未变时不会重新加载。搜索数量可能近似（`≈`）、未知（`?`）或受限（`≤`），部分页面无法访问时，换更具体的名称搜索。数量行的箭头可隐藏或显示列表而不丢失当前位置；先完成页码编辑，再收起。

切换声音，或替换、移除正在试听的卡片，会停止其试听。

## 3. 模型与费用

<a id="playback-and-cost"></a>
### 朗读前确认模型和资格

账号申请、充值、模型能力与收费以[官方文档](https://docs.fish.audio)和[API 计费说明](https://docs.fish.audio/developer-guide/models-pricing/pricing-and-rate-limits)为准。

**必须零费用时，先确认免费资格**。

必须零费用时，请按[官方活动条件](https://fish.audio/blog/s2-1-pro-free-api/)确认账号资格，再明确选择 `s2.1-pro-free`。必须零费用却无法确认资格时，只用搜索与试听，不执行合成。随机声音、有效 Key、名称含 free 或余额暂未变化，都不能单独证明免费。付费模型需要相应余额，并按前述官方 API 价格计费；扣款可能延迟，插件没有消费硬限额。

| 时间 | 可选模型与默认值 |
|---|---|
| 至 2026-11-30（UTC） | `s2.1-pro-free`、`drama-3`、`s2.1-pro`、`s2-pro`、`s1`；新配置默认免费模型。 |
| 自 2026-12-01（UTC）起 | 隐藏免费项，其余模型仍可选；列表第一项为 Drama 3，默认值为 `s2.1-pro`。 |

有效的已保存选择不会因列表重排而变化；不可用的选择会改为当时默认值。免费期结束后，该默认项 `s2.1-pro` 是付费模型。更新或免费期结束后，朗读前重新核对模型。免费推广卡可点击选择免费模型，关闭后记住隐藏；它不改变账号资格。

S1 目前仍可选；[官方说明](https://docs.fish.audio/api-reference/endpoint/websocket/tts-live)公告 2026-12-31 退役，之后指定 S1 的请求由 S2.1-Pro 提供。临近日期请检查官方价格和插件更新，不要假定保存的旧选择永远对应相同服务。

### 停止、替换与余额

在 STranslate 中停止朗读，或发起新的朗读，会取消旧播放；新朗读等待旧输出释放后开始。关闭或重新加载插件也会停止所属播放。运行中的朗读使用开始时的设置，之后的修改下次生效。

**停止不保证未计费**。

服务端可能已经生成或收费。断线、超时或播放错误后，插件不会自动再次合成或换用其他模型；修复后由你决定是否重试。余额更新可能滞后，旧余额不是费用保障。服务器排队、模型及网络会影响开始时间，免费模型也没有固定首音延迟保证。

## 4. 调整朗读

<a id="configuration"></a>
### 四个常用参数

编辑自动保存。以下为新配置默认值；可先一次调整一项，再比较听感。

| 参数 | 默认值 | 范围 | 作用 |
|---|---|---|---|
| 语速 | 1.0 | 0.5–2.0 | 调整朗读快慢。 |
| 音量 | 0 dB | -10–+10 dB | 调整合成音量；0 dB 是不增不减，不是静音。 |
| 表现力（Temperature） | 0.7 | 0–1 | 较高更富变化，较低更一致；0 可以使用。 |
| 多样性（Top P） | 0.7 | 0.05–1 | 调整采样多样性；这是插件允许范围。 |

三种操作都保留 0.01 精度：

- 点击滑条轨道或拖动滑块；或在滑条、尚未点击编辑的数字上悬停约 350 ms 后，用滚轮每格微调 0.01。
- 要精确输入，点击靠右显示的数字，在居中的输入框内键入；单位始终留在输入框外。Enter 或点击别处保存，Esc 取消。空白、无效或超范围的值会恢复原值。
- 使用小数点；所在区域使用小数逗号时，也可输入逗号。
### 其他选项

| 选项 | 默认值与用法 |
|---|---|
| 响度归一化 | 开启。仅在 `s2.1-pro-free`、`s2.1-pro`、`s2-pro` 显示。其他模型下隐藏但保留值，切回来恢复。 |
| 延迟模式 | 质量优先；也可选平衡、低延迟。可比较效果，但不保证固定启播时间。 |
| 文本规范化 | 关闭；可将数字、单位等转为更适合朗读的文本。 |
| 上下文关联 | 开启；利用本次合成的前序内容保持一致性，不引用以前其他朗读的音频。 |

长文本可在全部合成完成前开始播放。情绪、发音或说话人标记依模型支持而定；复杂或未闭合标记可能延迟开始，语法见[官方文档](https://docs.fish.audio)。插件不是完整的标记编辑器。

## 5. 选择格式与配置网络

<a id="audio-formats"></a>
### PCM 还是 MP3

| 格式 | 何时选择 |
|---|---|
| PCM | 新配置默认；避免压缩解码，但网络传输量较大。 |
| MP3 | 网络较慢或希望减少流量时可尝试。比特率可选 64 / 128 / 192 kbps，默认 192；越高越占带宽。 |

升级前的配置通常保留 MP3。PCM 下隐藏整项 MP3 比特率，切回 MP3 会恢复保存的值，其他朗读参数不受影响。目前不提供 WAV 或 Opus。格式不能单独保证首字速度；服务器、网络及输出设备同样有影响。

<a id="network-and-proxy"></a>
### 分别检查两条连接

声音列表能加载，不等于正式朗读已连通。收藏详情和试听也需要网络，保存的收藏不是离线音频。

| 功能 | 使用的网络设置 |
|---|---|
| 搜索、声音详情、余额、试听样本 | STranslate 宿主的 HTTP 网络设置。 |
| 正式朗读 | Windows 系统默认网络／代理，连接需允许 WebSocket。 |

插件没有单独的代理开关或地址栏。无法访问 Fish Audio，或出现“搜索成功但朗读失败”时，分别检查宿主网络和 Windows 系统网络／代理、代理程序是否运行、防火墙是否允许 WebSocket，再核对模型与账号权限。修复后手动重试，不要通过删除设置或收藏解决临时网络故障。

## 6. 排查问题并恢复操作

<a id="troubleshooting"></a>
### Key、连接与播放

| 现象 | 下一步 |
|---|---|
| 填 Key 后搜索失败 | 从官方页面重新复制有效 Key，避免额外空白或换行；也可清空 Key，先浏览公开声音。正式朗读与余额仍需有效 Key。 |
| 改 Key 后查询或试听停止 | 这是对旧工作的取消；显示的声音、选择和收藏保留，之后的查询使用新 Key。需要时重新查询或点击试听。 |
| Key 输入暂时不可编辑 | 等当前朗读或余额请求结束后再编辑。 |
| 余额查不到 | 检查 Key、账号权限和宿主网络，再点击刷新。 |
| 搜索成功，朗读失败 | 分别检查[两条连接](#network-and-proxy)，再确认模型可用及账号有权限。 |
| 首次播放等待较久 | 检查系统网络和输出设备，可比较 PCM／MP3；模型生成及免费队列仍会影响等待。 |
| 无声或中断 | 检查 Windows 输出设备、系统／应用音量及设备连接。修复后决定是否手动重试；音量 0 dB 不是静音。 |
| 停止后扣款／余额未变 | 停止不撤销服务端费用。等候后刷新余额，并向官方核对账单；[费用说明](#playback-and-cost)解释了相关限制。 |

### 声音、收藏与保存

| 现象 | 下一步 |
|---|---|
| 粘贴 ID 无效 | 重新复制 ID 本身，不要复制网址或额外文字。粘贴后查询，再应用。 |
| ID 查询错误提示消失 | 提示会在五秒后自动清除；修改 ID 或重新查询也会清除。消失不代表查询成功，检查 ID 或连接后再次查询，再应用结果。 |
| ID 查到声音但选择未变 | 点击结果的勾号 **应用**；试听和星标不会自动应用。 |
| 不能新增收藏 | 已有 300 个时先移除一个。否则重试保存；反复失败时保留原收藏，提交错误和操作步骤。 |
| 收藏只显示 ID | 检查宿主连接后重新打开收藏夹。已存 ID 仍保留，不再需要时可以取消收藏。 |
| 标题复制失败 | 稍等后再点一次标题；仍失败时，到该声音的[官方社区页面](https://fish.audio/app/discovery)复制 ID。 |
| 数字恢复旧值 | 输入[参数表](#configuration)范围内的值并按 Enter；Esc 会取消编辑。 |
| 保存错误反复出现 | 重新打开设置，检查实际保存值；仍有问题则报告错误与步骤。保留现有配置，不要清空。 |
| 卡片不见／没有更多页 | 先展开列表；若搜索受限，改用更具体名称。 |
| 试听失败／没有样本 | 检查宿主网络并重新查询。样本不可用时不会合成替代音频。 |

### 较少用到的设置问题

- 响度或比特率不显示时，检查所选模型及 PCM／MP3。切回支持的选项会恢复保存的值。
- 旧 Top P 的 0 会调整为 0.05；Temperature 的 0 仍有效，不需重置设置。
- **清理缓存** 只删封面图片，保留声音选择和收藏；之后封面重新下载是正常现象。

临时网络故障不需要删除配置或收藏。仍无法解决时，到 [Issues](https://github.com/Cirnouo/STranslate.Plugin.Tts.FishAudio/issues) 提供插件／宿主／Windows 版本、复现步骤、模型、格式、网络条件与脱敏错误。不要上传 API Key、完整签名 URL、代理密码或私人文本。开发与贡献见 [CONTRIBUTING](../../CONTRIBUTING.md)。
