<a id="installation"></a>
## インストールと更新

Windows の STranslate で **設定 → プラグイン → マーケット** を開き、**Fish Audio TTS** を検索してインストールします。

手動の場合は [Releases](https://github.com/Cirnouo/STranslate.Plugin.Tts.FishAudio/releases) から `STranslate.Plugin.Tts.FishAudio.spkg` を取得し、**設定 → プラグイン → インストール** から読み込みます。現在の安定版 STranslate を推奨します。使用 SDK は 1.0.15、互換性を検証した基準は STranslate v2.0.10 です。通常のインストールに .NET SDK の準備は不要です。SDK はソースからのビルドに使用します。

更新後は保存済みモデル、音声形式、ネットワーク設定を確認してください。通常の接続問題を調べるために設定を削除する必要はありません。変更点は[更新履歴](../../CHANGELOG.md)をご覧ください。

<a id="first-setup"></a>
## 初期設定

1. プラグイン設定の **API Key** に公式ページで作成したキーを貼り付けます。編集は自動保存され、確認操作は不要です。空白・改行を追加せず、実際のキーを公開しないでください。
2. 必要に応じて残高を更新します。起動時は通知なしで取得を試み、未取得時は更新を促す表示になります。残高取得や読み上げ中は API Key の入力が一時的にロックされます。
3. ボイスを検索・試聴してカードの チェック（**適用**） を押します。**ID で指定** の虫眼鏡で照会してから結果を適用するか、**お気に入り** から選ぶこともできます。未指定ならランダムボイスです。
4. 合成モデルと PCM/MP3 を確認し、STranslate で短文を読み上げます。支出をゼロにする必要がある場合は、先に[料金の注意点](#playback-and-cost)を確認してください。試験呼び出し自体では無料資格を確認できません。

検索、ID 照会、試聴は API Key なしで使えます。合成と残高照会には利用可能なキーが必要です。旧形式の小文字 16 進数 32 文字、および `sk-fish-` に有効な 43 文字が続く新形式に対応します。形式チェックの通過は認証成功や残高を保証しません。

キー未設定時、ボイス一覧・詳細の取得には `dummy` を使います。設定後は入力したキーを使い、お気に入りの読み込み、起動時のボイス更新、試聴リンクの更新にも適用します。キーが拒否されても `dummy` では再試行しません。試聴音声とカバー画像の取得にはキーを付けません。キー変更時は古い照会を取り消し、表示済みの検索・ID 検索結果、お気に入り、選択中のボイス情報は保持します。次の照会から新しいキーを使います。共有メモリキャッシュのメタデータは認証情報ごとに分離し、異なるキーの情報を混用しません。

表示言語は STranslate に自動追従し、简体中文、繁體中文、English、日本語、한국어 に対応します。プラグイン専用の言語設定はありません。表示言語と読み上げ言語は独立しており、モデルの対応言語は公式資料をご確認ください。

API Key と ID の貼り付けアイコンは入力欄の右内側にあり、文字領域を確保しています。キーは貼り付け後も自動保存されます。ID の貼り付けは入力のみで、虫眼鏡または Enter で照会し、結果を別途適用します。

ボイス ID 欄は ASCII の小文字 16 進数（`0–9`、`a–f`）を最大 32 文字まで途中入力できますが、照会には 32 文字すべてが必要です。不正な入力文字は表示しません。Ctrl+V と欄内の貼り付けボタンは、不正な貼り付け全体を拒否して元の入力を保持します。大文字、空白、URL、長すぎる内容は受け付けず、空白除去、ID 抽出、小文字変換、切り詰めは行いません。

<a id="voices"></a>
## ボイスの検索・選択・試聴

タブは **検索**、**ID で指定**、**お気に入り** の順です。選択中のタブはホバー・押下中もアクセント色を保ちます。選択中・検索・ID・お気に入りカードは ID ごとに同期し、未適用はチェック、現在の適用 ID はクロスを表示します。ツールチップ／アクセシブル名は「適用」「クリア」で、統一した枠なしアイコンにホバー・キーボードフォーカス表示を残します。同 ID のどのクロスでも現在の選択を解除します。照会・試聴・お気に入りは選択と独立しています。

選択中カードは常にクロス／クリアです。同 ID の閲覧カードもクロスとなり、ID だけの仮表示でも解除できます。未適用の仮表示で適用する場合だけ、有効な詳細取得を待ちます。適用／解除の設定保存に失敗した場合は元の選択とカード状態を維持します。

ID がある選択中・検索・ID 照会・お気に入りのカードでは、タイトルをクリックするとその ID をクリップボードへコピーできます。成功時はフローティング通知、失敗時はエラーを表示します。作者名・説明文は通常の文字で、このコピー操作はありません。コピーはボイスの適用・試聴を実行せず、お気に入りも変更しません。

**検索** タブで名前を入力し、検索ボタンまたは Enter で実行します。入力の編集だけでは検索しません。新しい検索が成功すると結果とクエリを適用し、1 ページ目へ戻ります。試聴は公開サンプルを再生し、チェック（**適用**） でボイスを選びます。選択中カードと同 ID の閲覧カードは試聴状態を共有します。準備中は回転表示と取り消し用の四角、実再生後は進捗を表示します。取得・再生中に再度押すと停止し、別ボイスへの切り替えでも旧試聴が止まります。

検索結果は初回展開です。件数行の右に文字見出しのないアイコンだけの開閉ボタンがあり、下のヒント・カード・ページ操作を切り替えます。件数行は常に表示します。クエリ、結果、ページ、選択は残り、現在の設定ビューではタブ変更や再検索後も状態を維持します。ページ編集中は Enter で確定するか元に戻してから閉じてください。フォーカス移動で番号が確定するためです。

検索・お気に入りのページ送りは枠なし `‹` / `›` アイコンです。ツールチップとアクセシブル名を「前へ」「次へ」とし、文字や矩形ボタンは表示しません。番号入力後 Enter／フォーカス移動でも確定します。検索は元データ 6 件から非 TTS を除外します。`≈` は概数、`?` は不明、`≤` はアクセス可能上限です。公式ウィンドウは一部だけの場合があり、上限不明時は訪問済みと許可された次ページのみ使えます。失敗・空ページは自動で飛ばしません。

**ID で指定** に小文字 16 進数 32 文字の ID を入力し、虫眼鏡または Enter で照会します。試聴・星・選択アイコンのカード 1 枚を取得するだけで選択は変えません。未適用はチェック（**適用**）、適用済み ID はクロス（**クリア**）で、後者は選択を解除します。入力編集・再照会で旧カードは消え、ページ送り／折りたたみはありません。[公式コミュニティ](https://fish.audio/app/discovery)のボイス「Model ID」は `s2.1-pro` などのエンジン名とは別です。選択カードや同 ID のどの結果でもクロスでランダムに戻り、モデル・お気に入り・料金規則は保持します。

### お気に入り

「お気に入り」タブには星アイコンがあります。選択／適用済みカードも ID があれば同じ星を表示し、検索・ID・お気に入りと共通の ID リストへ登録／解除して状態を同期します。登録操作は現在の選択を変えません。ランダムボイスには登録できる固定 ID がありません。

輪郭のみの星は未登録、金色の塗りつぶしは登録済みです。クリックで切り替え、検索・ID・お気に入りの同 ID カードで同期します。登録と適用は独立し、解除しても選択ボイスは消えません。**お気に入り** は ID タブの右にあり、ホストが本プラグインに用意した設定フォルダーの `favorite-voices.json` に ID だけの順序付き JSON 配列を保存します。メタデータは主設定に保存せず、Fish Audio アカウントとの同期もありません。再起動後も ID は残り、表示情報は共有メモリキャッシュから、未取得ならボイス詳細照会から読み込みます。

初期リストは空、最大 300 件です。上限時は先に 1 件解除し、既存項目を自動削除しません。ファイル保存成功後に星・一覧を反映し、失敗時は旧状態を保持します。1 ページ 6 件で件数・ページ数は正確なローカル値です。前後や番号入力後 Enter／フォーカス移動で移動し、解除保存後すぐ更新します。末尾ページが空でも他に項目が残る場合は、前の有効ページへ戻ります。全件空なら空リストの案内だけを表示し、件数・開閉操作・ページ送りは表示しません。最後の項目を削除する前に折りたたんでいても案内は表示します。保存領域のエラーは別途通知します。詳細未取得でもプレースホルダーと解除操作を残し、有効な情報取得前は適用不可です。通信失敗や見つからない応答でも ID を自動削除しません。

お気に入りが空でないときは、件数行の右に独立したアイコンだけの開閉操作があります。件数は残り、ヒント・カード・ページ操作だけを閉じます。初期は展開で、現在ビューのタブ・一覧変更でも維持し、検索側には影響しません。番号編集は先に確定してください。検索・ID・お気に入り・試聴詳細更新は容量制限のあるメモリ内メタデータキャッシュを共有し、再起動後には残りません。音声キャッシュではありません。カバー画像は既存の共有永続キャッシュを使い、画像削除は ID を消しません。メタデータ取得済みでもサンプル URL の有効期限確認は行います。ページ変更、発信元の解除、ID 結果置換は試聴を止め、遅延応答は旧項目や再生を復活させません。

試聴は TTS を呼び出しません。有効なサンプル URL は再利用でき、毎回詳細を更新しません。署名 URL は期限の 30 秒前から更新し、署名時刻が欠落・不正な場合も安全側で更新します。サンプルの 403/404 は詳細更新と再試行を各 1 回まで許可しますが、先に期限更新した場合は同じ更新枠を消費済みです。すべての URL に署名があるわけではなく、署名なしも永久有効の保証ではありません。サンプル欠落や更新失敗時に代替音声を合成しません。

検索・ID・お気に入りは、ホストがプラグイン用に提供するキャッシュフォルダーの `cover_images` を、ボイス ID ごとに共有します。お気に入り用に画像を複製しません。ローカル画像を優先し、なければ再取得して保存します。キャッシュ削除はこの画像のみで、別の設定フォルダーにあるお気に入り ID ファイルや共有メタデータは消しません。削除後、既存カードは元のリモート画像 URL を使います。以後の検索、ID 照会、お気に入りページの読み込み時に、画像を再取得してキャッシュできます。

再生をまたぐ音声キャッシュはありません。毎回ホスト HTTP でサンプルを取得し、その再生用メモリを停止・終了・失敗時に解放します。選択ボイスのキャッシュはメタデータと URL、カバーキャッシュは画像のみです。試聴進捗は出力の再生位置で、ダウンロード進捗ではありません。

共有メタデータキャッシュは LRU 方式で最大 300 件を保持し、単調時計で計るクライアント有効期間は 15 分です。同じアプリ内のプラグイン再初期化では共有し、アプリ再起動後には残りません。検索・詳細の応答で更新し、登録操作では期限延長や新しい情報の置換をしません。試聴 URL の期限切れ／403/404 はキャッシュを迂回して詳細更新し、1 回の更新枠を維持します。15 分は URL 有効期間の保証ではありません。

<a id="configuration"></a>
## 設定一覧

編集項目は自動保存されます。以下は新規設定の既定値です。旧設定の形式移行は後述します。ボイスは声質、合成モデルはエンジン、API Key はアカウント認証を決めます。

速度、音量、表現力（Temperature）、多様性（Top P）は数値を直接入力できます。スライダー右の数字をクリックすると同じ固定サイズの入力欄になり、`dB` などの単位は外に残ります。フォーカスを移すか Enter を押すと検証・保存してスライダーへ反映し、Esc で取り消します。空欄、不正な形式、非有限値、範囲外の値は確定済みの値へ戻ります。4 項目とも小数 2 桁で表示・保存し、ドラッグ、ホイール、直接入力の精度を 0.01 に統一します。Top P の `0.82` や音量 `1.03 dB` も保持されます。

スライダー上、または編集中でない数値表示にポインターを重ねてホイールを回すと、4 項目とも 1 段階 0.01 で微調整でき、許容範囲の上下限で止まります。トラック、つまみ、数値表示が対象で、隣の単位は含みません。この間、設定ページはスクロールしません。スライダー上でホイールを使うとドラッグ時と同じ現在値の吹き出しが表示され、短い待機後またはポインターが離れると消えます。数値入力欄上のホイールは値を変えず、ページを通常どおりスクロールします。

編集中の数値は ASCII 数字 `0–9`、最大 1 個の小数点、音量のみ先頭の負号を受け付けます。`.` を使え、現在の地域設定が小数コンマを使う場合だけ `,` も使えます。速度・表現力・Top P は最大 4 文字、整数 1 桁と小数 2 桁まで、音量は最大 6 文字、整数 2 桁と小数 2 桁までです（例：`-10.00`）。文字種や桁数に反する入力は表示せず、不正な貼り付けは全体を拒否して現在の編集内容を保持します。途中の未完成入力は許可し、数値の範囲は確定時に検証します。

| 項目 | 既定値 | 範囲・動作 |
|---|---|---|
| API Key | 空 | 合成・残高照会用。貼り付け可能。 |
| ボイス ID | 空／ランダム | 検索・ID・お気に入りカードの チェック（**適用**） で選択。未指定は無料を意味しません。 |
| お気に入り | 空リスト | 別ファイルに順序付き ID のみ保存。最大 300 件、1 ページ 6 件。星で登録／解除、同期なし。 |
| 合成モデル | 無料期間は `s2.1-pro-free`、以後 `s2.1-pro` | 一覧と既定選択の規則は下記。 |
| 音声形式 | PCM | PCM / MP3。旧設定では通常 MP3 を維持。 |
| MP3 ビットレート | 192 kbps | 64 / 128 / 192。PCM では項目全体を隠し、MP3 に戻すと保持した値を表示。 |
| 速度 | 1.0 | 0.5–2.0。ドラッグ・ホイール・直接入力とも 0.01 精度。 |
| 音量 | 0 dB | -10–+10 dB。ドラッグ・ホイール・直接入力とも 0.01 精度。合成時の音量差で、ミュートではありません。 |
| ラウドネス正規化 | オン | S2 系列に対応。許可した 3 モデルのみ表示・送信し、それ以外は値を保持して非表示。 |
| 表現力 | 0.7 | 0–1。ドラッグ・ホイール・直接入力とも 0.01 精度。高いほど変化、低いほど一貫性。 |
| 多様性 | 0.7 | プラグインの範囲は 0.05–1。ドラッグ・ホイール・直接入力とも 0.01 精度。Top P 制御。 |
| レイテンシ | 品質優先（`normal`） | 品質優先／バランス（`balanced`）／低レイテンシ（`low`）。固定の発声開始時間は保証しません。 |
| テキスト正規化 | オフ | 数字や単位などを読みやすいテキストに変換。 |
| コンテキスト連携 | オン | 今回の合成の前のチャンクを利用。過去の別音声は参照しません。 |
| 残高更新 | 起動時に静かに試行 | 手動時は応答時間表示、合成成功後は静かに更新。支出上限ではありません。 |
| カバーキャッシュ | 自動 | ディスク使用量と削除操作。ボイス ID／情報／お気に入りは保持。 |
| 無料モデル案内カード | 未閉じ | クリックで無料を選択。閉じると非表示を記憶し、利用資格は変えません。 |
| 表示言語 | ホストに追従 | 5 言語。個別設定なし。 |

ラウドネス正規化は `s2.1-pro-free`、`s2.1-pro`、`s2-pro` のみ表示し、`normalize_loudness` を送ります。S1 では効果がなく、Drama 3 は対応未確認のため現在のクライアント能力方針で非表示です。Drama 3 のサーバー非対応を実証したという意味ではありません。非表示でも値を保持し、要求項目を省略します。許可モデルに戻すと値を復元します。

**2026-12-01T00:00:00Z より前**は `s2.1-pro-free`、`drama-3`、`s2.1-pro`、`s2-pro`、`s1` の順で、既定は無料モデルです。それ以後は無料項目を隠し、残りの先頭は Drama 3 ですが、既定は `s2.1-pro` です。一覧順と既定選択は独立しています。有効な保存済み選択は並べ替えで変わらず、利用不能な選択はその時点の既定に修正します。キャンペーンは[公式条件](https://fish.audio/blog/s2-1-pro-free-api/)に従います。

現在は S1 も選択可能です。[公式 WS 資料](https://docs.fish.audio/api-reference/endpoint/websocket/tts-live)では 2026-12-31 の提供終了と、以後 S1 指定リクエストを S2.1-Pro で提供することを告知しています。期日前後は料金とプラグイン更新を確認してください。

主設定は SchemaVersion=2 です。バージョンなし／1 からは有効項目を保持し、形式の欠落・不正時は MP3 にして有効なビットレートを維持します。新規は PCM。お気に入り ID は別ファイルで、主設定のメタデータ項目でも新スキーマでもありません。形式変更は他項目や非表示の MP3 値を消さず、モデル変更も非表示のラウドネス値を保持します。設定読み込み時の範囲外数値は既定に戻し、有効値はスライダーの刻みではなく表示精度に丸めます。未来版／重複バージョンは主設定を上書き保護するため、手動で番号を下げないでください。

旧ストリーミングプロキシのモード／アドレスは無効となり、対応設定の通常保存で削除されます。スキーマは 2 のままです。

Top P の 0.05 下限はクライアント互換方針であり、公式 API の最小値を断定しません。保存済み 0 は 0.05 へ、負数・非有限値・1 超は既定 0.7 へ修正します。表現力（Temperature）は 0 を引き続き受け付け、範囲は 0–1 です。

<a id="audio-formats"></a>
## PCM と MP3

PCM は 44.1 kHz、16 ビット、モノラルで、圧縮デコード不要ですが約 88,200 バイト／秒です。MP3 は継続デコードを行い、64/128/192 kbps で通信量を抑えられます。高ビットレートほど帯域を使います。低速回線では MP3、圧縮処理を避けたい場合は PCM を試してください。サーバー待ち、回線、デバイスバッファ、冒頭の無音も開始時間に影響するため、形式だけで発声開始時間は保証できません。

長文は必要に応じて分割送信し、音声を受信・再生します。通常の文は全体の合成を待たずに開始できますが、複雑／未閉鎖の感情・音素マークアップは安全な区切りを遅らせます。入力順は保持しますが、完全なマークアップエディターではありません。モデル固有の感情・発音・話者構文は[公式資料](https://docs.fish.audio)へ。WAV/Opus は選択できません。

<a id="network-and-proxy"></a>
## ネットワークとシステム接続

正式な読み上げはネイティブ WebSocket を使い、常にシステム既定プロキシに従います。プラグイン内に独立したプロキシ切り替え、モード、アドレス設定はありません。検索・詳細・残高・試聴サンプルは STranslate ホストの HTTP 設定を使います。HTTP の成功だけでは WebSocket 接続の成功を示しません。

検索だけ成功する場合は Windows のシステム通信／プロキシ、プロキシサービスの稼働、WebSocket を許可するファイアウォール、モデルとアカウント権限を確認してください。プラグイン内でプロキシ欄を探す必要はありません。修正後に手動で再試行し、自動モデル変更や再合成は行いません。

<a id="playback-and-cost"></a>
## 再生・停止・料金

STranslate の読み上げから使います。新しい読み上げは旧セッションを取り消し、出力の解放を待ちます。ホストの停止、初期化世代の終了、アプリ終了でも取り消します。実行中は開始時の設定を使い、その後の編集は次回に反映します。正常終了は受信済みの実音声が再生されるまで待ちます。

取り消しはクライアントの停止で、未生成／未課金の証明ではありません。切断・タイムアウト・デコード失敗で自動的に再合成したり、有料モデル／HTTP／別経路へ切り替えたりしません。ただし期限切れモデルは起動時に現在の既定へ修正されるため、更新やキャンペーン終了後は選択を確認してください。

支出を厳密にゼロにする場合、現在の公式条件で無料利用を確認し、明示的に `s2.1-pro-free` を選んだ場合だけ合成してください。確認できなければ検索・試聴に留めます。ランダムボイス、キー形式、残高未変化、名前の free だけでは無料を証明できません。有料モデルにはクレジットが必要で、反映に遅延があり、プラグインに支出のハード上限はありません。無料サービスの初音時間も保証されません。

<a id="troubleshooting"></a>
## 問題の対処

| 症状 | 確認・対処 |
|---|---|
| ラウドネス非表示／旧 Top P が 0.05 | 表示はクライアント許可モデルに従い値は保持します。Top P の旧 0 は下限へ、Temperature の 0 はそのまま有効です。 |
| Key 形式エラー | 公式からコピーし直し、空白・改行を除去。ボイス ID と混同しない。 |
| 検索成功、合成失敗 | ホスト HTTP とシステム WebSocket の経路、モデル可用性、アカウント権限を個別確認。 |
| 総数が大きいのに次ページなし | 検索ウィンドウ制限の可能性。より具体的な名前で検索。 |
| 折りたたみ後カードがない | 再展開。クエリ、ページ、選択は維持されています。 |
| ID 成功後も選択が変わらない | 結果の チェック（**適用**） を押す。照会・試聴・星だけでは適用しません。 |
| 追加不可／仮表示のまま | 300 件上限、ファイル保存案内、ボイス詳細の接続を確認。取得失敗でも ID は残り、解除可能です。 |
| 試聴失敗／サンプルなし | ホスト通信を確認。期限切れなら詳細を再照会。TTS 代替は行いません。 |
| 初回再生が遅い | システム通信・出力を確認し PCM/MP3 を比較。無料キューの影響は残ります。 |
| 無音／中断 | Windows の出力、システム／アプリ音量、デバイス接続を確認して手動再試行。 |
| 残高が変わらない | 待って手動更新。古い残高は無料の証拠ではありません。 |
| 削除後カバーを再取得 | 正常動作。画像のみ削除し、ボイス設定・お気に入りは保持します。 |

解決しなければ [Issues](https://github.com/Cirnouo/STranslate.Plugin.Tts.FishAudio/issues) にプラグイン／ホスト／Windows 版、再現手順、モデル／形式とシステム通信条件、機密情報を除いたエラーを記載してください。Key、署名 URL 全文、代理パスワード、私的な読み上げ文は送信しないでください。開発は [CONTRIBUTING](../../CONTRIBUTING.md)をご覧ください。
