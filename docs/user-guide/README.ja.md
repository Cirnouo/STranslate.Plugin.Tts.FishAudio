## 1. 使い始める

<a id="installation"></a>
### インストール

Windows の STranslate で **設定 → プラグイン → マーケット** を開き、**Fish Audio TTS** を検索してインストールします。

<a id="first-setup"></a>
### 最初の読み上げを行う

検索、ID 照会、公開サンプルの試聴はキーなしで使えますが、接続は必要です。正式な読み上げと残高照会には有効な Fish Audio API Key が必要です。

1. [公式 API Key ページ](https://fish.audio/app/api-keys)でキーを作成し、プラグインの **API Key** に貼り付けます。自動保存されます。空白・改行を追加せず、キーを公開しないでください。
2. **検索** でボイスを探し、試聴して **適用** を押します。未指定のランダムボイスでも使えます。
3. 合成モデルと[料金条件](#playback-and-cost)を確認します。支出ゼロが必要なら、公式の無料資格を確認して `s2.1-pro-free` を明示的に選んでから、試験読み上げを行います。
4. STranslate に戻り、**Fish Audio TTS** を選んで短文を読み上げます。

### 必要に応じて：残高・手動インストール・更新

残高を確認したい場合は、残高更新を押します。

手動の場合は [Releases](https://github.com/Cirnouo/STranslate.Plugin.Tts.FishAudio/releases) から `STranslate.Plugin.Tts.FishAudio.spkg` を取得し、**設定 → プラグイン → インストール** で読み込みます。

安定版 STranslate を推奨します。互換性の検証基準は v2.0.10 です。更新後は保存したモデル、形式、接続設定を確認し、変更点は[更新履歴](../../CHANGELOG.md)をご覧ください。

表示言語はホストに追従し、简体中文、繁體中文、English、日本語、한국어、Русский、Türkçe に対応します。個別の言語設定はありません。表示言語とモデルが読み上げられる言語は別で、後者は[公式資料](https://docs.fish.audio)をご確認ください。

## 2. ボイスを選ぶ・管理する

<a id="voices"></a>
### 3 つの入口から探す

ボイスは声質、モデルは合成エンジンを決めます。コミュニティのボイス「Model ID」は声の素材の ID で、`s2.1-pro` などのエンジン名ではありません。

| タブ | 操作 |
|---|---|
| **検索** | 名前を入力し、検索または Enter で実行します。 |
| **ID で指定** | [公式コミュニティ](https://fish.audio/app/discovery)やカードのタイトルから ID をコピーします。URL でなく ID だけを貼り、虫眼鏡または Enter で照会してから、結果の **適用** を押します。 |
| **いいね** | ローカルに保存したボイスを開き、詳細取得後に試聴・適用します。 |

| したいこと | 操作 |
|---|---|
| サンプルを聴く | 再生を押し、もう一度押すと停止します。既存の公開サンプルを使い、ボイスの適用や自分の文章の合成はしません。 |
| 読み上げに使う | チェックの **適用** を押します。ランダムに戻すにはクロスの **クリア** を押します。モデルといいねしたボイスは残ります。ランダムは無料を意味しません。 |
| 後で使うために保存 | 「いいね」で保存し、「いいねを取り消す」で解除します。解除しても使用中のボイスはクリアしません。ランダムボイスには保存できる固定 ID がありません。 |
| ボイス ID をコピー | 作者や説明ではなく、カードの **タイトル** を押します。 |

検索欄の**検索オプション**で、**すべての言語**を選ぶか、言語タイルで複数選択します。「すべての言語」は個別の選択を解除し、最後の個別言語を解除すると「すべての言語」に戻ります。10 個すべてを選んでも、そのプリセットへの絞り込みです。複数言語の組み合わせ方は Fish Audio が決定します。並べ替えは**関連度優先**、**利用回数優先**、**新着順**です。**適用**を押すとオプションが閉じ、現在の検索文字で 1 ページ目をすぐに更新します。変更がなくても更新します。**リセット**は下書きを「すべての言語＋関連度優先」に戻すだけで、**閉じる**は変更を破棄します。検索や Enter は適用済みのオプションを使い、ページ移動では最後に成功した検索を保持します。オプションは今回の設定セッションだけ有効です。更新に失敗した場合、以前の結果とオプションは残ります。

検索、ID で指定、いいねしたボイス、選択中のボイスには、同じ言語ラベルが独立した 1 行で表示されます。各ラベルは旗と表示言語に合わせた言語名で、カードの幅に収まるだけ表示され、3 個という固定上限はありません。`+N` を押すと、残り N 言語だけをポップアップで確認できます。言語名は常に残り、最初のラベルの名前さえ収まらない場合だけ省略記号で短縮されます。マウスを重ねると完全な名前を確認できます。言語メタデータがない場合は行全体が非表示になります。ラベルは Fish Audio のボイスメタデータに基づき、合成可能言語の固定リスト、話者の国籍、エンジンの全言語能力を示すものではありません。不明な言語コードは文字を残し、汎用アイコンで表示します。

カード右下にはシステムのタイムゾーンに換算した作成日（`yyyy-MM-dd`）が表示され、ホバーすると時差を含む完全な日時を確認できます。不明または無効な場合は `—` です。説明が空の場合は行全体が折りたたまれ、余白は残りません。

いいねしたボイスはこの PC に保存され、再起動後も残り、Fish Audio アカウントとは同期しません。最大 300 件で、上限では先に 1 件解除します。詳細や試聴には接続が必要ですが、取得失敗で保存した項目は削除されません。

検索といいねしたボイスは `‹` / `›` でページを移動できます。ページ番号欄は数字のみ受け付け、現在アクセスできる最大ページを超えると直ちに上限へ補正されます。別の番号を入力して欄から離れるか、Enter を押すと移動します。同じページ番号では再読み込みしません。検索件数は概数（`≈`）、不明（`?`）、制限付き（`≤`）の場合があるため、先へ進めなければ名前を具体化して検索します。件数行の矢印で現在位置を保ったまま一覧を開閉できます。番号編集を終えてから折りたたんでください。

ボイスの変更や、試聴中カードの置換・削除で、その試聴は止まります。

## 3. モデルと料金

<a id="playback-and-cost"></a>
### 読み上げ前にモデルと資格を確認する

アカウント登録、チャージ、機能、料金は[公式資料](https://docs.fish.audio)と [API 料金](https://docs.fish.audio/developer-guide/models-pricing/pricing-and-rate-limits)に従います。

**支出ゼロが必要な場合は、先に無料資格を確認**。

支出ゼロが必要な場合は、[公式キャンペーン条件](https://fish.audio/blog/s2-1-pro-free-api/)でアカウントの資格を確認し、明示的に `s2.1-pro-free` を選んでください。支出ゼロが必要で資格を確認できなければ、検索と試聴に留めて合成しません。ランダムボイス、有効なキー、名前の free、残高未変化だけでは無料と判断できません。有料モデルは上記の公式 API 料金に従い、クレジットが必要です。反映は遅れることがあり、プラグインに支出のハード上限はありません。

| 期間 | 選べるモデルと既定値 |
|---|---|
| 2026年11月30日まで（UTC） | `s2.1-pro-free`、`drama-3`、`s2.1-pro`、`s2-pro`、`s1`。新規設定は無料モデルが既定です。 |
| 2026年12月1日から（UTC） | 無料項目を隠し、残りのモデルを表示します。先頭は Drama 3、既定は `s2.1-pro` です。 |

有効な保存済み選択は並べ替えで変わりません。利用できなくなった選択は、その時点の既定へ変わります。無料期間後の既定 `s2.1-pro` は有料モデルです。更新や無料期間終了後は読み上げ前にモデルを再確認してください。無料モデルの案内カードを押すと無料を選択し、閉じると非表示を記憶します。利用資格自体は変えません。

S1 は現在も選べます。[公式告知](https://docs.fish.audio/api-reference/endpoint/websocket/tts-live)は 2026-12-31 の提供終了と、以後の S1 指定を S2.1-Pro で処理することを案内しています。期日前後は料金とプラグイン更新を確認し、保存した選択が永久に同じサービスを指すとは考えないでください。

### 停止・置き換え・残高

STranslate で停止するか、新しい読み上げを始めると、古い再生を取り消します。新しい読み上げは旧出力の解放を待ちます。プラグインの終了・再読み込みでも再生は停止します。実行中は開始時の設定を使い、後の編集は次回に反映します。

**停止しても未課金とは限りません**。

サーバーは既に生成・課金している可能性があります。切断、タイムアウト、再生エラーで自動的に再合成やモデル変更はしません。修正後に再試行するか判断してください。残高更新は遅れる場合があり、古い残高は支出の保障になりません。サーバー待ち、モデル、接続が開始時間に影響し、無料モデルにも固定の初音時間保証はありません。

## 4. 読み上げを調整する

<a id="configuration"></a>
### よく使う 4 項目

編集は自動保存されます。以下は新規設定の既定値です。まず 1 項目ずつ変えて聴き比べてください。

| 項目 | 既定値 | 範囲 | 効果 |
|---|---|---|---|
| 速度 | 1.0 | 0.5–2.0 | 読み上げの速さを変えます。 |
| 音量 | 0 dB | -10–+10 dB | 合成音量の増減。0 dB は変更なしで、ミュートではありません。 |
| 表現力（Temperature） | 0.7 | 0–1 | 高いほど変化、低いほど一貫性が増します。0 も有効です。 |
| 多様性（Top P） | 0.7 | 0.05–1 | サンプリングの多様性を調整。これはプラグインの許容範囲です。 |

次の 3 操作はいずれも 0.01 精度を保ちます。

- スライダーのトラックをクリックするか、つまみをドラッグします。またはスライダーや編集中でない数字の上に約 350 ms ポインターを置き、ホイールで 0.01 ずつ調整します。
- 正確な値は右揃えの数字をクリックし、中央揃えの入力欄で入力します。単位は入力欄の外に残ります。Enter または別の場所をクリックすると保存し、Esc で取り消します。空欄、不正、範囲外の値は以前の値に戻ります。
- 小数点を使います。地域設定が小数コンマならコンマも使えます。
### その他の設定

| 項目 | 既定値と使い方 |
|---|---|
| ラウドネス正規化 | オン。`s2.1-pro-free`、`s2.1-pro`、`s2-pro` のみ表示します。他モデルでは値を保持して隠し、戻すと復元します。 |
| レイテンシ | 品質優先。バランス、低レイテンシも選べます。効果を比較できますが、一定の開始時間は保証しません。 |
| テキスト正規化 | オフ。数字や単位などを読みやすい文章へ変換できます。 |
| コンテキスト連携 | オン。今回の合成の前の内容を使い、過去の別の読み上げ音声は使いません。 |

長文は全体の合成終了前に再生を始められます。感情・発音・話者マークアップはモデルごとに異なり、複雑なものや閉じていない記述は開始を遅らせることがあります。構文は[公式資料](https://docs.fish.audio)へ。プラグインは完全なマークアップエディターではありません。

## 5. 形式を選び、接続を確認する

<a id="audio-formats"></a>
### PCM と MP3 を選ぶ

| 形式 | 選ぶ目安 |
|---|---|
| PCM | 新規設定の既定値。圧縮デコードを避けられますが、通信量は多くなります。 |
| MP3 | 低速回線や通信量を抑えたい場合に試します。64 / 128 / 192 kbps、既定は 192。高い値ほど帯域が必要です。 |

以前の設定は通常 MP3 を維持します。PCM ではビットレート項目全体を隠し、MP3 に戻すと保存値を復元します。他の読み上げ設定は変わりません。WAV、Opus は選べません。形式だけで発声開始速度は保証できず、サーバー、接続、出力装置も影響します。

<a id="network-and-proxy"></a>
### 2 つの接続を別々に確認する

ボイス一覧を取得できても、音声合成が接続できるとは限りません。いいねしたボイスの詳細や試聴にも接続が必要で、保存したいいねしたボイスはオフライン音声ではありません。

| 機能 | 使用する接続設定 |
|---|---|
| 検索、ボイス詳細、残高、試聴サンプル | STranslate ホストの HTTP 設定。 |
| 音声合成 | Windows のシステム既定ネットワーク／プロキシ。WebSocket を許可する必要があります。 |

プラグイン専用のプロキシ切り替え・アドレス欄はありません。接続できない場合や検索だけ成功する場合は、ホスト設定と Windows のシステム設定を別々に確認します。プロキシの稼働、ファイアウォールの WebSocket 許可、モデルとアカウントの権限も確認し、修正後に手動再試行します。一時的なネットワーク問題のために設定やいいねしたボイスを削除しないでください。

## 6. 問題を解決し、操作を再開する

<a id="troubleshooting"></a>
### キー・接続・再生

| 症状 | 次の操作 |
|---|---|
| キー入力後に検索が失敗 | 公式から空白・改行を付けず有効なキーをコピーし直すか、キーを空にして公開ボイスを閲覧します。合成と残高には引き続き有効なキーが必要です。 |
| キーを変えると照会・試聴が止まる | 以前の作業は取り消しますが、表示中のボイス、選択、いいねしたボイスは残ります。以後の照会は新しいキーを使います。必要なら照会・試聴を再度開始します。 |
| キーを一時的に編集できない | 実行中の読み上げや残高照会が終わるまで待ちます。 |
| 残高が取れない | キー、アカウント権限、ホスト接続を確認して更新します。 |
| 検索成功、読み上げ失敗 | [2 つの接続](#network-and-proxy)、モデルの利用可否、アカウント権限を確認します。 |
| 音声まで長く待つ | システム接続と出力装置を確認し、PCM／MP3 を比較します。モデル生成や無料キューの待ちは残り得ます。 |
| 無音／中断 | Windows 出力、システム／アプリ音量、装置接続を確認し、修正後に再試行を判断します。音量 0 dB はミュートではありません。 |
| 停止後に課金／残高未変化 | 停止はサーバーの課金を取り消しません。待って残高を更新し、公式の請求を確認します。制約は[料金説明](#playback-and-cost)をご覧ください。 |

<a id="ボイスお気に入り保存"></a>

### ボイス・いいねしたボイス・保存

| 症状 | 次の操作 |
|---|---|
| ID を貼り付けられない | URL や余分な文字を付けず ID だけをコピーし直し、照会してから適用します。 |
| ID 照会のエラー表示が消える | エラーは五秒後、ID の編集時、または次の照会開始時に消えます。表示が消えても照会成功を意味しません。ID や接続を確認して再照会し、結果を適用してください。 |
| ID が見つかっても選択が変わらない | 結果のチェック **適用** を押します。試聴やハートでは適用されません。 |
| いいねできない | 300 件なら先に 1 件解除します。それ以外は保存を再試行し、繰り返すなら既存項目を保ったままエラーと手順を報告します。 |
| いいねしたボイスに ID だけ表示 | ホスト接続を確認し、いいねしたボイスを開き直します。保存 ID は残り、不要なら解除できます。 |
| タイトルのコピー失敗 | 少し待って再度タイトルを押します。続く場合はそのボイスの[公式コミュニティページ](https://fish.audio/app/discovery)から ID をコピーします。 |
| 数字が元に戻る | [表の範囲](#configuration)の値を Enter で確定します。Esc は編集取消です。 |
| 保存エラーが繰り返す | 設定を開き直して保存値を確認します。続く場合はエラーと手順を報告し、設定は残します。 |
| カードがない／続きのページがない | まず一覧を展開します。検索制限なら名前を具体化します。 |
| 試聴失敗／サンプルなし | ホスト接続を確認して再照会します。サンプルの代わりに音声を合成しません。 |

### その他の設定の疑問

- ラウドネスやビットレートはモデルと PCM／MP3 に連動します。対応する選択へ戻すと保存値を復元します。
- 古い Top P の 0 は 0.05 になります。Temperature の 0 は有効で、設定の初期化は不要です。
- キャッシュ削除はカバー画像だけを消し、選択といいねしたボイスは残します。後の画像再取得は正常です。

一時的な接続障害で設定やいいねしたボイスを消す必要はありません。解決しない場合は [Issues](https://github.com/Cirnouo/STranslate.Plugin.Tts.FishAudio/issues) にプラグイン／ホスト／Windows 版、再現手順、モデル、形式、接続条件、機密情報を除いたエラーを記載します。API Key、署名 URL 全文、プロキシのパスワード、私的な文章は送らないでください。開発・貢献は [CONTRIBUTING](../../CONTRIBUTING.md)へ。
