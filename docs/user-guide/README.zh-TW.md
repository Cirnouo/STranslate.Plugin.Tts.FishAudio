## 1. 開始使用

<a id="installation"></a>
### 安裝

在 Windows 的 STranslate 開啟 **設定 → 外掛 → 市集**，搜尋 **Fish Audio TTS** 並安裝。

**網路前提**：中國大陸網路無法存取 `fish.audio` 服務。請先完成本頁[網路檢查](#network-and-proxy)，再設定與朗讀。

<a id="first-setup"></a>
### 完成第一次朗讀

搜尋、ID 查詢與公開樣本試聽可不填 Key，但仍需連線。正式朗讀與餘額查詢需要有效的 Fish Audio API Key。

1. 在[官方 API Key 頁面](https://fish.audio/app/api-keys)建立 Key，貼入外掛的 **API Key**，輸入自動儲存。不要附加空白或換行，也不要公開金鑰。
2. 在 **搜尋** 找到聲音，試聽後按 **套用**；也可不選聲音，使用隨機音色。
3. 選擇合成模型並核對[費用條件](#playback-and-cost)。必須零費用時，先確認官方資格，再明確選用 `s2.1-pro-free`，之後才開始任何測試朗讀。
4. 回到 STranslate，選用 **Fish Audio TTS** 朗讀一小段文字。

### 選用：餘額、手動安裝與更新

需要查看餘額時，點擊餘額重新整理即可。

手動安裝可從 [Releases](https://github.com/Cirnouo/STranslate.Plugin.Tts.FishAudio/releases) 下載 `STranslate.Plugin.Tts.FishAudio.spkg`，再從 **設定 → 外掛 → 安裝** 匯入。

建議使用穩定版 STranslate，已驗證相容基線為 v2.0.10。更新後檢查已存模型、格式與網路設定，變更見[更新紀錄](../../CHANGELOG.md)。

介面跟隨宿主，支援简体中文、繁體中文、English、日本語、한국어、Русский、Türkçe，無獨立語言選項。介面語言與模型可朗讀的語言不同，後者見[官方文件](https://docs.fish.audio)。

## 2. 選擇與管理聲音

<a id="voices"></a>
### 從三個入口找聲音

聲音決定音色，模型決定合成引擎。社群聲音的「模型 ID」是聲音資產 ID，不是 `s2.1-pro` 等引擎名稱。

| 入口 | 操作 |
|---|---|
| **搜尋** | 輸入名稱，按搜尋或 Enter。 |
| **透過 ID** | 從[官方社群](https://fish.audio/app/discovery)或卡片標題複製 ID，只貼 ID 本身而非網址。按放大鏡或 Enter 查詢，再按結果的 **套用**。 |
| **收藏夾** | 開啟本機儲存的聲音，詳細資料載入後試聽或套用。 |

| 想做什麼 | 操作 |
|---|---|
| 聽樣本 | 按播放，再按一次停止。試聽使用現成公開樣本，不會套用聲音或合成你的文字。 |
| 用於朗讀 | 按勾號 **套用**。要恢復隨機聲音，按叉號 **清除**；模型與收藏保留。隨機聲音不代表免費。 |
| 留待以後使用 | 按星號新增或取消收藏；取消收藏不會清除目前使用的聲音。隨機聲音沒有可收藏的固定 ID。 |
| 複製聲音 ID | 按卡片的 **標題**，不是作者或描述。 |

搜尋、透過 ID、收藏夾和已選聲音使用相同的語言標籤，在獨立單行中顯示旗幟與目前介面語言的名稱。卡片越寬，可顯示的標籤越多，沒有固定三個的上限；按 `+N` 可在彈出視窗中查看恰好剩餘的 N 種語言。名稱始終保留，僅當第一個標籤的完整名稱也放不下時用刪節號縮短，懸停可查看全名。缺少語言中繼資料時隱藏整列。標籤來自 Fish Audio 的聲音中繼資料，不是固定的合成語言白名單、說話者國籍或引擎完整語言能力說明；無法辨識的語言代碼保留原文字並顯示通用圖示。

收藏保存在本機，重新啟動後保留，不與 Fish Audio 帳戶同步。最多 300 個，達上限先移除一個。詳細資料與試聽仍需連線，查詢失敗不會刪除已存收藏。

搜尋與收藏可用 `‹` / `›` 翻頁，頁碼欄僅接受數字，超過目前可存取最大頁碼時會立即調回上限。輸入新頁碼後離開欄位即可跳轉，也可按 Enter；頁碼未變時不會重新載入。搜尋數量可能近似（`≈`）、未知（`?`）或受限（`≤`），部分頁面無法存取時，改用更具體的名稱搜尋。數量列的箭頭可隱藏或顯示清單而不丟失目前位置；先完成頁碼編輯，再收合。

切換聲音，或替換、移除正在試聽的卡片，會停止其試聽。

## 3. 模型與費用

<a id="playback-and-cost"></a>
### 朗讀前確認模型與資格

帳戶申請、儲值、模型能力及收費以[官方文件](https://docs.fish.audio)與[API 計費說明](https://docs.fish.audio/developer-guide/models-pricing/pricing-and-rate-limits)為準。

**必須零費用時，先確認免費資格**。

必須零費用時，請按[官方活動條件](https://fish.audio/blog/s2-1-pro-free-api/)確認帳戶資格，再明確選擇 `s2.1-pro-free`。必須零費用卻無法確認資格時，只用搜尋與試聽，不執行合成。隨機聲音、有效 Key、名稱含 free 或餘額暫未變化，都不能單獨證明免費。付費模型需要相應餘額，並按前述官方 API 價格計費；扣款可能延遲，外掛沒有消費硬上限。

| 時間 | 可選模型與預設值 |
|---|---|
| 至 2026-11-30（UTC） | `s2.1-pro-free`、`drama-3`、`s2.1-pro`、`s2-pro`、`s1`；新設定預設免費模型。 |
| 自 2026-12-01（UTC）起 | 隱藏免費項，其餘模型仍可選；清單首項為 Drama 3，預設值為 `s2.1-pro`。 |

有效的已存選擇不因清單重排而改變；無法使用的選擇會改成當時預設值。免費期結束後，預設項 `s2.1-pro` 是付費模型。更新或免費期結束後，朗讀前重新核對模型。免費推廣卡可點擊選擇免費模型，關閉後記住隱藏；不會改變帳戶資格。

S1 目前仍可選；[官方說明](https://docs.fish.audio/api-reference/endpoint/websocket/tts-live)公告 2026-12-31 退役，之後指定 S1 的請求由 S2.1-Pro 提供。接近該日期請確認官方價格及外掛更新，不要假設舊選擇永久對應相同服務。

### 停止、替換與餘額

在 STranslate 停止朗讀，或發起新朗讀，會取消舊播放；新朗讀等候舊輸出釋放後開始。關閉或重新載入外掛也會停止所屬播放。執行中的朗讀使用開始時的設定，之後修改下次生效。

**停止不保證未計費**。

服務端可能已生成或收費。斷線、逾時或播放錯誤後，外掛不會自動再次合成或改用其他模型；修復原因後由你決定是否重試。餘額更新可能滯後，舊餘額不是費用保障。伺服器排隊、模型及網路影響啟播，免費模型也不保證固定首音延遲。

## 4. 調整朗讀

<a id="configuration"></a>
### 四個常用參數

編輯自動儲存。以下為新設定預設值；可先每次調整一項，再比較聽感。

| 參數 | 預設值 | 範圍 | 作用 |
|---|---|---|---|
| 語速 | 1.0 | 0.5–2.0 | 調整朗讀快慢。 |
| 音量 | 0 dB | -10–+10 dB | 調整合成音量；0 dB 代表不增不減，不是靜音。 |
| 表現力（Temperature） | 0.7 | 0–1 | 越高越多變，越低越一致；0 可使用。 |
| 多樣性（Top P） | 0.7 | 0.05–1 | 調整取樣多樣性；這是外掛允許範圍。 |

三種操作皆保留 0.01 精度：

- 點擊滑桿軌道或拖曳滑塊；或在滑桿、尚未點擊編輯的數字上停留約 350 ms 後，用滾輪每格微調 0.01。
- 要精確輸入，按數字後鍵入；Enter 或點擊別處儲存，Esc 取消。空白、無效或超範圍值會恢復原值。
- 使用小數點；所在地區採小數逗號時，也可輸入逗號。
### 其他選項

| 選項 | 預設值與用法 |
|---|---|
| 響度歸一化 | 開啟。僅在 `s2.1-pro-free`、`s2.1-pro`、`s2-pro` 顯示。其他模型隱藏但保留值，切回時恢復。 |
| 延遲模式 | 品質優先；也可選平衡、低延遲。可比較效果，但不保證固定啟播時間。 |
| 文字規範化 | 關閉；可將數字、單位等轉成適合朗讀的文字。 |
| 上下文關聯 | 開啟；利用本次合成的前序內容維持一致性，不引用以前其他朗讀的音訊。 |

長文可在全部合成完成前開始播放。情緒、發音或說話人標記依模型支援而定；複雜或未閉合標記可能延遲啟播，語法見[官方文件](https://docs.fish.audio)。外掛不是完整的標記編輯器。

## 5. 選擇格式與設定網路

<a id="audio-formats"></a>
### PCM 還是 MP3

| 格式 | 何時選擇 |
|---|---|
| PCM | 新設定預設；避免壓縮解碼，但網路傳輸量較大。 |
| MP3 | 網路較慢或希望減少流量時可嘗試。位元率可選 64 / 128 / 192 kbps，預設 192；越高越占頻寬。 |

升級前的設定通常保留 MP3。PCM 隱藏整項 MP3 位元率，切回 MP3 會恢復已存值，其他朗讀參數不受影響。目前不提供 WAV 或 Opus。格式不能單獨保證首字速度，伺服器、連線與輸出裝置同樣有影響。

<a id="network-and-proxy"></a>
### 分別檢查兩條連線

聲音清單能載入，不代表正式朗讀已連通。收藏詳情及試聽也需連線，保存的收藏不是離線音訊。

| 功能 | 使用的網路設定 |
|---|---|
| 搜尋、聲音詳情、餘額、試聽樣本 | STranslate 宿主的 HTTP 網路設定。 |
| 正式朗讀 | Windows 系統預設網路／代理，連線必須允許 WebSocket。 |

外掛沒有獨立代理開關或位址欄。無法存取 Fish Audio，或「搜尋成功但朗讀失敗」時，分別檢查宿主網路、Windows 系統網路／代理、代理程式是否執行及防火牆是否允許 WebSocket，再核對模型與帳戶權限。修復後手動重試，不要刪除設定或收藏來解決暫時的網路故障。

## 6. 排查問題並恢復操作

<a id="troubleshooting"></a>
### Key、連線與播放

| 現象 | 下一步 |
|---|---|
| 填 Key 後搜尋失敗 | 從官方頁面重新複製有效 Key，避免額外空白或換行；也可清空 Key，先瀏覽公開聲音。正式朗讀與餘額仍需有效 Key。 |
| 改 Key 後查詢或試聽停止 | 這會取消舊工作；顯示的聲音、選擇與收藏保留，之後的查詢使用新 Key。需要時重新查詢或按試聽。 |
| Key 暫時無法編輯 | 等目前朗讀或餘額請求結束後再編輯。 |
| 無法查詢餘額 | 檢查 Key、帳戶權限與宿主連線，再重新整理。 |
| 搜尋成功，朗讀失敗 | 分別檢查[兩條連線](#network-and-proxy)，再確認模型可用及帳戶權限。 |
| 首次播放等待較久 | 檢查系統網路與輸出裝置，可比較 PCM／MP3；模型生成及免費佇列仍影響等待。 |
| 無聲或中斷 | 檢查 Windows 輸出、系統／應用程式音量及裝置連線。修復後決定是否手動重試；音量 0 dB 不是靜音。 |
| 停止後扣款／餘額未變 | 停止不撤銷服務端費用。等候後更新餘額，並向官方核對帳單；[費用說明](#playback-and-cost)解釋了相關限制。 |

### 聲音、收藏與儲存

| 現象 | 下一步 |
|---|---|
| ID 貼上無效 | 重新複製 ID 本身，不要複製網址或額外文字。貼上後查詢，再套用。 |
| ID 查詢錯誤提示消失 | 提示會在五秒後自動清除；修改 ID 或重新查詢也會清除。消失不代表查詢成功，檢查 ID 或連線後再次查詢，再套用結果。 |
| 查到聲音但選擇未變 | 按結果的勾號 **套用**；試聽與星號不會自動套用。 |
| 無法新增收藏 | 已有 300 個時先移除一個。否則重試儲存；反覆失敗時保留原收藏，提交錯誤與操作步驟。 |
| 收藏只顯示 ID | 檢查宿主連線後重新開啟收藏夾。已存 ID 仍保留，不再需要時可取消收藏。 |
| 標題複製失敗 | 稍等後再按一次標題；仍失敗時，到該聲音的[官方社群頁面](https://fish.audio/app/discovery)複製 ID。 |
| 數字恢復舊值 | 輸入[參數表](#configuration)範圍內的值並按 Enter；Esc 會取消編輯。 |
| 儲存錯誤反覆出現 | 重新開啟設定，檢查實際儲存值；仍有問題則報告錯誤與步驟。保留現有設定，不要清空。 |
| 卡片不見／沒有更多頁 | 先展開清單；若搜尋受限，改用更具體名稱。 |
| 試聽失敗／無樣本 | 檢查宿主網路後重新查詢。樣本無法使用時不會合成替代音訊。 |

### 較少用到的設定問題

- 響度或位元率不顯示時，檢查所選模型與 PCM／MP3。切回支援的選項會恢復儲存值。
- 舊 Top P 的 0 會調整至 0.05；Temperature 的 0 仍有效，不需重設設定。
- **清理快取** 只刪封面圖片，保留聲音選擇與收藏；之後封面重新下載是正常現象。

暫時網路故障不需刪除設定或收藏。仍無法解決時，到 [Issues](https://github.com/Cirnouo/STranslate.Plugin.Tts.FishAudio/issues) 提供外掛／宿主／Windows 版本、重現步驟、模型、格式、網路條件及去識別化錯誤。不要上傳 API Key、完整簽名 URL、代理密碼或私人文字。開發與貢獻見 [CONTRIBUTING](../../CONTRIBUTING.md)。
