## 1. 시작하기

<a id="installation"></a>
### 설치

Windows의 STranslate에서 **설정 → 플러그인 → 마켓**을 열고 **Fish Audio TTS**를 찾아 설치합니다.

<a id="first-setup"></a>
### 첫 읽기 완료하기

검색, ID 조회와 공개 샘플 미리 듣기는 키 없이 가능하지만 네트워크는 필요합니다. 정식 읽기와 잔액 조회에는 유효한 Fish Audio API Key가 필요합니다.

1. [공식 API Key 페이지](https://fish.audio/app/api-keys)에서 키를 만들고 플러그인의 **API Key**에 붙여 넣습니다. 자동 저장됩니다. 공백·줄바꿈을 덧붙이거나 키를 공개하지 마세요.
2. **검색**에서 보이스를 찾아 미리 듣고 **적용**을 누릅니다. 지정하지 않고 임의 보이스를 써도 됩니다.
3. 합성 모델과 [비용 조건](#playback-and-cost)을 확인합니다. 지출이 0이어야 한다면 공식 자격을 확인하고 `s2.1-pro-free`를 명시적으로 선택한 뒤에 테스트 읽기를 시작하세요.
4. STranslate로 돌아가 **Fish Audio TTS**를 선택하고 짧은 문장을 읽습니다.

### 선택 사항: 잔액, 수동 설치와 업데이트

잔액을 확인하려면 잔액 새로 고침을 누릅니다.

수동 설치는 [Releases](https://github.com/Cirnouo/STranslate.Plugin.Tts.FishAudio/releases)에서 `STranslate.Plugin.Tts.FishAudio.spkg`를 받아 **설정 → 플러그인 → 설치**에서 가져옵니다.

안정 버전 STranslate를 권장하며 검증한 호환성 기준은 v2.0.10입니다. 업데이트 후 저장된 모델·형식·네트워크를 확인하고 [변경 기록](../../CHANGELOG.md)을 참고하세요.

화면 언어는 호스트를 따르며 简体中文, 繁體中文, English, 日本語, 한국어, Русский, Türkçe를 지원합니다. 별도 언어 선택은 없습니다. 화면 언어와 모델이 읽을 수 있는 언어는 다르며 후자는 [공식 문서](https://docs.fish.audio)를 확인하세요.

## 2. 보이스 선택과 관리

<a id="voices"></a>
### 세 가지 경로로 찾기

보이스는 음색, 모델은 합성 엔진을 결정합니다. 커뮤니티 보이스의 “Model ID”는 음성 자산 ID이며 `s2.1-pro` 같은 엔진 이름이 아닙니다.

| 탭 | 사용 방법 |
|---|---|
| **검색** | 이름을 입력하고 검색 또는 Enter를 누릅니다. |
| **ID로 지정** | [공식 커뮤니티](https://fish.audio/app/discovery)나 카드 제목에서 ID를 복사합니다. URL 대신 ID만 붙여 넣고 돋보기 또는 Enter로 조회한 뒤 결과의 **적용**을 누릅니다. |
| **즐겨찾기** | 로컬에 저장한 보이스를 열고 상세 정보가 로드되면 미리 듣거나 적용합니다. |

| 하려는 일 | 동작 |
|---|---|
| 샘플 듣기 | 재생을 누르고 다시 누르면 멈춥니다. 기존 공개 샘플을 사용하며 보이스를 적용하거나 내 텍스트를 합성하지 않습니다. |
| 읽기에 사용 | 체크 **적용**을 누릅니다. 임의 보이스로 돌아가려면 X **지우기**를 누르세요. 모델과 즐겨찾기는 남습니다. 임의 보이스는 무료를 뜻하지 않습니다. |
| 나중을 위해 저장 | 별을 눌러 추가·제거합니다. 제거해도 사용 중인 보이스는 지워지지 않습니다. 임의 보이스에는 저장할 고정 ID가 없습니다. |
| 보이스 ID 복사 | 작성자나 설명이 아닌 카드 **제목**을 누릅니다. |

검색 입력란의 **검색 옵션**에서 **모든 언어**를 선택하거나 언어 타일을 여러 개 선택합니다. 모든 언어는 개별 선택을 해제하며 마지막 개별 언어를 해제하면 모든 언어로 돌아갑니다. 10개를 모두 선택해도 해당 프리셋으로 필터링합니다. 여러 언어의 조합 방식은 Fish Audio가 결정합니다. 정렬은 **관련성 우선**, **많이 사용한 순**, **최신순** 중에서 고릅니다. **적용**하면 옵션이 닫히고 현재 검색어로 첫 페이지를 즉시 새로 고칩니다. 변경 사항이 없어도 새로 고칩니다. **초기화**는 적용 전 옵션만 모든 언어와 관련성 우선으로 되돌리며, **닫기**는 변경을 취소합니다. 검색이나 Enter는 적용한 옵션을 사용하고 페이지를 바꾸면 마지막으로 성공한 검색을 유지합니다. 옵션은 현재 설정 세션에만 유지되며 새로 고침에 실패하면 기존 결과와 옵션이 남습니다.

검색, ID로 지정, 즐겨찾기와 선택한 보이스는 별도의 한 줄에 같은 언어 라벨을 표시합니다. 각 라벨은 국기와 현재 인터페이스 언어로 된 언어 이름으로 구성되며, 카드 너비에 맞는 만큼 표시되고 3개로 고정된 상한은 없습니다. `+N`을 누르면 남은 N개 언어만 팝업에서 확인할 수 있습니다. 언어 이름은 항상 유지되며 첫 라벨의 전체 이름도 들어가지 않을 때만 말줄임표로 줄입니다. 마우스를 올리면 전체 이름을 볼 수 있습니다. 언어 메타데이터가 없으면 행 전체를 숨깁니다. 라벨은 Fish Audio 보이스 메타데이터이며, 합성 언어의 고정 허용 목록이나 화자의 국적 또는 엔진의 전체 언어 기능을 뜻하지 않습니다. 알 수 없는 언어 코드는 텍스트를 유지하고 일반 아이콘을 표시합니다.

카드 오른쪽 아래에는 시스템 시간대로 변환한 생성 날짜(`yyyy-MM-dd`)가 표시됩니다. 마우스를 올리면 UTC 오프셋을 포함한 전체 시간을 볼 수 있으며, 날짜가 없거나 잘못된 경우 `—`로 표시됩니다. 설명이 비어 있으면 해당 행 전체가 접혀 언어, 작성자와 인기도가 위로 이동합니다.

즐겨찾기는 이 컴퓨터에 저장되고 재시작 후에도 남으며 Fish Audio 계정과 동기화하지 않습니다. 최대 300개로 상한에서는 하나를 먼저 제거하세요. 상세와 미리 듣기는 네트워크가 필요하지만 조회 실패로 저장 항목을 삭제하지는 않습니다.

검색과 즐겨찾기는 `‹` / `›`로 페이지를 이동합니다. 페이지 입력란은 숫자만 허용하며 현재 접근 가능한 최대 페이지를 넘으면 즉시 상한으로 조정합니다. 다른 페이지 번호를 입력하고 입력란을 벗어나거나 Enter를 누르면 이동하며, 같은 페이지 번호로는 다시 로드하지 않습니다. 검색 총수는 근사값(`≈`), 미상(`?`), 제한값(`≤`)일 수 있으므로 더 갈 수 없다면 구체적인 이름으로 검색하세요. 개수 행의 화살표로 현재 위치를 유지하며 목록을 접고 펼칩니다. 페이지 편집을 끝낸 뒤 접으세요.

보이스를 바꾸거나 미리 듣는 카드를 교체·제거하면 해당 미리 듣기가 멈춥니다.

## 3. 모델과 비용

<a id="playback-and-cost"></a>
### 읽기 전에 모델과 자격 확인하기

계정 가입, 충전, 기능과 요금은 [공식 문서](https://docs.fish.audio) 및 [API 요금 안내](https://docs.fish.audio/developer-guide/models-pricing/pricing-and-rate-limits)를 따릅니다.

**지출이 0이어야 한다면 먼저 무료 자격을 확인하세요**.

지출이 0이어야 한다면 [공식 프로모션 조건](https://fish.audio/blog/s2-1-pro-free-api/)에서 계정 자격을 확인한 뒤 `s2.1-pro-free`를 명시적으로 선택하세요. 지출이 0이어야 하는데 자격을 확인할 수 없다면 검색과 미리 듣기만 사용하고 합성하지 마세요. 임의 보이스, 유효한 키, 이름의 free 또는 그대로인 잔액만으로 무료라고 판단할 수 없습니다. 유료 모델에는 크레딧이 필요하며 위의 공식 API 요금이 적용됩니다. 차감은 늦게 반영될 수 있고 플러그인에는 지출 하드 한도가 없습니다.

| 기간 | 선택 가능한 모델과 기본값 |
|---|---|
| 2026년 11월 30일까지(UTC) | `s2.1-pro-free`, `drama-3`, `s2.1-pro`, `s2-pro`, `s1`. 새 설정의 기본값은 무료 모델입니다. |
| 2026년 12월 1일부터(UTC) | 무료 항목을 숨기고 나머지는 유지합니다. 목록 첫 항목은 Drama 3이지만 기본값은 `s2.1-pro`입니다. |

유효한 저장 선택은 순서 변경으로 바뀌지 않지만 사용할 수 없는 선택은 당시 기본값으로 바뀝니다. 무료 기간 후 기본값인 `s2.1-pro`는 유료 모델입니다. 업데이트나 무료 기간 종료 후에는 읽기 전에 모델을 다시 확인하세요. 무료 모델 안내 카드를 누르면 무료 모델을 선택하고 닫으면 숨김을 기억합니다. 계정 자격 자체는 바꾸지 않습니다.

현재는 S1도 선택할 수 있습니다. [공식 안내](https://docs.fish.audio/api-reference/endpoint/websocket/tts-live)는 2026-12-31 제공 종료와 이후 S1 지정 요청을 S2.1-Pro로 처리하는 것을 알립니다. 해당 시기에는 가격과 플러그인 업데이트를 확인하고 저장한 선택이 영원히 같은 서비스를 뜻한다고 생각하지 마세요.

### 중지, 교체와 잔액

STranslate에서 중지하거나 새 읽기를 시작하면 이전 재생을 취소합니다. 새 읽기는 이전 출력을 해제할 때까지 기다립니다. 플러그인을 닫거나 다시 로드해도 해당 재생이 멈춥니다. 실행 중에는 시작 시 설정을 사용하고 나중의 편집은 다음 읽기에 적용합니다.

**중지는 미청구를 보장하지 않습니다**.

서버가 이미 생성하거나 청구했을 수 있습니다. 연결 끊김, 시간 초과나 재생 오류가 나도 자동 재합성이나 모델 변경은 하지 않습니다. 원인을 고친 뒤 재시도할지 결정하세요. 잔액 반영은 늦을 수 있으며 이전 잔액은 비용 보장이 아닙니다. 서버 대기, 모델과 네트워크가 시작 시간에 영향을 주며 무료 모델도 고정된 첫 오디오 시간을 보장하지 않습니다.

## 4. 읽기 조절

<a id="configuration"></a>
### 자주 쓰는 네 가지 값

편집은 자동 저장됩니다. 아래는 새 설정의 기본값입니다. 한 번에 하나씩 바꾸어 들어 보세요.

| 설정 | 기본값 | 범위 | 효과 |
|---|---|---|---|
| 속도 | 1.0 | 0.5–2.0 | 읽는 속도를 바꿉니다. |
| 음량 | 0 dB | -10–+10 dB | 합성 음량을 조절합니다. 0 dB는 증감 없음이며 음소거가 아닙니다. |
| 표현력(Temperature) | 0.7 | 0–1 | 높을수록 다양하고 낮을수록 일관적입니다. 0도 유효합니다. |
| 다양성(Top P) | 0.7 | 0.05–1 | 샘플링 다양성을 조절합니다. 플러그인이 허용하는 범위입니다. |

세 방법 모두 0.01 정밀도를 유지합니다.

- 슬라이더 트랙을 클릭하거나 손잡이를 끌거나, 슬라이더 또는 편집 중이 아닌 숫자 위에 약 350 ms 머문 뒤 휠로 0.01씩 조절합니다.
- 정확한 값은 오른쪽 정렬된 숫자를 누른 뒤 가운데 정렬된 입력란에서 입력합니다. 단위는 입력란 밖에 표시됩니다. Enter나 다른 곳을 클릭하면 저장하고 Esc는 취소합니다. 빈 값, 잘못된 값이나 범위 밖 값은 이전 값으로 돌아갑니다.
- 소수점을 사용하거나 현재 지역에서 사용하는 소수 쉼표를 쓸 수 있습니다.
### 기타 옵션

| 옵션 | 기본값과 사용법 |
|---|---|
| 라우드니스 정규화 | 켜짐. `s2.1-pro-free`, `s2.1-pro`, `s2-pro`에서만 보입니다. 다른 모델에서는 값을 보존하고 숨기며 돌아오면 복원합니다.  |
| 지연 모드 | 품질 우선. 균형·저지연도 선택할 수 있습니다. 결과를 비교할 수 있지만 일정한 시작 시간을 보장하지는 않습니다. |
| 텍스트 정규화 | 꺼짐. 숫자·단위 등을 읽기 좋은 텍스트로 바꿀 수 있습니다. |
| 컨텍스트 연동 | 켜짐. 이번 합성의 앞선 내용을 이용하며 과거의 다른 읽기 오디오는 쓰지 않습니다. |

긴 글은 전체 합성이 끝나기 전에 재생을 시작할 수 있습니다. 감정·발음·화자 표시는 모델 지원에 따르며 복잡하거나 닫히지 않은 표시는 시작을 늦출 수 있습니다. 문법은 [공식 문서](https://docs.fish.audio)를 참고하세요. 플러그인은 완전한 마크업 편집기는 아닙니다.

## 5. 형식 선택과 네트워크 설정

<a id="audio-formats"></a>
### PCM과 MP3 선택

| 형식 | 선택할 때 |
|---|---|
| PCM | 새 설정의 기본값. 압축 디코딩을 피하지만 네트워크 전송량은 더 큽니다. |
| MP3 | 느린 연결이나 트래픽을 줄일 때 시도합니다. 64 / 128 / 192 kbps 중 선택하며 기본값은 192입니다. 높을수록 대역폭이 더 필요합니다. |

이전 설정은 보통 MP3를 유지합니다. PCM은 비트레이트 항목 전체를 숨기며 MP3로 돌아오면 저장한 값을 복원합니다. 다른 읽기 설정은 바뀌지 않습니다. WAV와 Opus는 선택할 수 없습니다. 형식만으로 첫 단어 속도를 보장할 수 없고 서버·연결·출력 장치도 영향을 줍니다.

<a id="network-and-proxy"></a>
### 두 연결을 따로 확인하기

보이스 목록을 불러와도 음성 합성 연결까지 확인된 것은 아닙니다. 즐겨찾기 상세와 미리 듣기도 네트워크가 필요하며 저장한 즐겨찾기는 오프라인 오디오가 아닙니다.

| 기능 | 사용하는 네트워크 설정 |
|---|---|
| 검색, 보이스 상세, 잔액, 미리 듣기 샘플 | STranslate 호스트 HTTP 설정. |
| 음성 합성 | Windows 시스템 기본 네트워크/프록시. 연결에서 WebSocket을 허용해야 합니다. |

플러그인에는 별도 프록시 스위치나 주소 입력란이 없습니다. Fish Audio에 연결되지 않거나 검색만 성공하면 호스트 설정과 Windows 시스템 설정을 각각 확인하세요. 프록시 실행 여부, 방화벽의 WebSocket 허용, 모델과 계정 권한도 확인한 뒤 수동 재시도합니다. 일시적인 연결 문제를 고치려고 설정이나 즐겨찾기를 지우지 마세요.

## 6. 문제 해결과 작업 복구

<a id="troubleshooting"></a>
### 키, 연결과 재생

| 현상 | 다음 조치 |
|---|---|
| 키 입력 후 검색 실패 | 공식 페이지에서 공백·줄바꿈 없이 유효한 키를 다시 복사하거나, 키를 비워 공개 보이스를 탐색합니다. 합성과 잔액에는 여전히 유효한 키가 필요합니다. |
| 키를 바꾸면 조회·미리 듣기가 멈춤 | 이전 작업은 취소하지만 표시된 보이스, 선택과 즐겨찾기는 유지됩니다. 이후 조회는 새 키를 사용합니다. 필요하면 조회·미리 듣기를 다시 시작하세요. |
| 키를 잠시 편집할 수 없음 | 현재 읽기나 잔액 요청이 끝날 때까지 기다립니다. |
| 잔액 조회 불가 | 키, 계정 권한과 호스트 연결을 확인하고 새로 고칩니다. |
| 검색 성공, 읽기 실패 | [두 연결](#network-and-proxy), 모델 가용성과 계정 권한을 확인합니다. |
| 오디오까지 오래 기다림 | 시스템 연결과 출력 장치를 확인하고 PCM/MP3를 비교합니다. 모델 생성과 무료 대기는 여전히 영향을 줄 수 있습니다. |
| 무음 / 중단 | Windows 출력, 시스템/앱 음량과 장치 연결을 확인한 뒤 재시도할지 결정합니다. 음량 0 dB는 음소거가 아닙니다. |
| 중지 후 요금 / 잔액 그대로 | 중지가 서버 청구를 취소하지는 않습니다. 기다렸다 잔액을 새로 고치고 공식 청구 내역을 확인하세요. 제약은 [비용 안내](#playback-and-cost)에 있습니다. |

### 보이스, 즐겨찾기와 저장

| 현상 | 다음 조치 |
|---|---|
| ID 붙여넣기 거부 | URL이나 다른 글자 없이 ID만 다시 복사하고 조회한 뒤 적용합니다. |
| ID 조회 오류가 사라짐 | 오류는 5초 후 또는 ID를 수정하거나 새 조회를 시작하면 지워집니다. 사라졌다고 조회에 성공한 것은 아닙니다. ID나 연결을 확인하고 다시 조회한 뒤 결과를 적용하세요. |
| ID가 있어도 선택이 안 바뀜 | 결과의 체크 **적용**을 누릅니다. 미리 듣기와 별은 적용하지 않습니다. |
| 즐겨찾기 추가 불가 | 300개라면 먼저 하나를 제거합니다. 그렇지 않으면 저장을 재시도하고, 반복 실패 시 기존 항목을 유지하며 오류와 단계를 보고하세요. |
| 즐겨찾기에 ID만 표시 | 호스트 연결을 확인한 뒤 즐겨찾기를 다시 엽니다. 저장 ID는 남으며 필요 없으면 제거할 수 있습니다. |
| 제목 복사 실패 | 잠시 기다렸다 제목을 다시 누릅니다. 계속 실패하면 해당 보이스의 [공식 커뮤니티 페이지](https://fish.audio/app/discovery)에서 ID를 복사하세요. |
| 숫자가 이전 값으로 돌아감 | [표의 범위](#configuration) 안의 값을 Enter로 확정합니다. Esc는 편집 취소입니다. |
| 저장 오류가 반복됨 | 설정을 다시 열어 저장된 값을 확인합니다. 지속되면 오류와 단계를 보고하고 기존 설정은 유지하세요. |
| 카드 없음 / 다음 페이지 없음 | 먼저 목록을 펼칩니다. 검색이 제한되면 더 구체적인 이름을 사용하세요. |
| 미리 듣기 실패 / 샘플 없음 | 호스트 연결을 확인한 뒤 다시 조회합니다. 샘플 대신 음성을 합성하지 않습니다. |

### 덜 자주 쓰는 설정 질문

- 라우드니스와 비트레이트는 모델 및 PCM/MP3 선택을 따릅니다. 지원하는 선택으로 돌아오면 저장값을 복원합니다.
- 이전 Top P의 0은 0.05가 됩니다. Temperature의 0은 유효하며 설정을 초기화할 필요는 없습니다.
- **캐시 지우기**는 표지만 지우고 선택과 즐겨찾기는 남깁니다. 이후 표지가 다시 다운로드되는 것은 정상입니다.

일시적 연결 문제 때문에 설정이나 즐겨찾기를 지울 필요는 없습니다. 해결되지 않으면 [Issues](https://github.com/Cirnouo/STranslate.Plugin.Tts.FishAudio/issues)에 플러그인/호스트/Windows 버전, 재현 단계, 모델, 형식, 연결 조건과 민감 정보를 뺀 오류를 적어 주세요. API Key, 전체 서명 URL, 프록시 암호나 개인 텍스트는 올리지 마세요. 개발과 기여는 [CONTRIBUTING](../../CONTRIBUTING.md)를 참고하세요.
