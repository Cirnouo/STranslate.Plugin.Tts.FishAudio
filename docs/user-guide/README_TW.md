<a id="installation"></a>
## 安裝與更新

在 Windows 上使用 STranslate。建議進入 **設定 → 外掛 → 市集**，搜尋 **Fish Audio TTS** 並下載安裝。

手動安裝時，從 [Releases](https://github.com/Cirnouo/STranslate.Plugin.Tts.FishAudio/releases) 下載 `STranslate.Plugin.Tts.FishAudio.spkg`，在 STranslate 的 **設定 → 外掛 → 安裝** 中匯入。優先使用目前穩定版 STranslate；此外掛採用 SDK 1.0.15，經驗證的相容基線是 STranslate v2.0.10。一般安裝不需要自行設定 .NET SDK；SDK 僅供原始碼建置使用。

更新後請核對已儲存的模型、音訊格式及網路設定。排查一般連線問題時，不需要刪除設定。版本變更見[更新紀錄](../../CHANGELOG.md)。

<a id="first-setup"></a>
## 首次設定

1. 開啟外掛設定，將官方頁面建立的金鑰貼入 **API Key**。輸入會自動儲存，不需要確認；請勿加入空白或換行，也不要公開真實金鑰。
2. 需要時點擊餘額重新整理。啟動時會靜默嘗試載入，尚未取得結果時顯示「點擊重新整理」。餘額請求及朗讀期間會暫時鎖定 API Key 輸入，結束後恢復。
3. 搜尋並試聽聲音，按卡片的勾號（**套用**）；或切換至 **透過 ID** 用放大鏡查詢，再按結果卡片的勾號（**套用**）。也可從 **收藏夾** 選用，或保留隨機聲音。
4. 核對合成模型並選擇 PCM 或 MP3，再於 STranslate 朗讀短文。若必須零費用，先閱讀[費用限制](#playback-and-cost)，不要用測試請求代替免費資格核實。

搜尋、透過 ID 查詢與試聽不需要 API Key；合成及餘額查詢需要有效金鑰。外掛相容舊版 32 位小寫十六進位 Key，以及 `sk-fish-` 後接 43 位合法字元的新版 Key。本機格式通過不代表帳戶驗證成功或餘額足夠。

未設定 Key 時，聲音清單與詳細資料查詢使用 `dummy`；設定後使用填入的 Key，包含收藏夾載入、啟動聲音重新整理與試聽連結更新。Key 被拒絕時不會改用 `dummy` 重試。試聽音訊與封面下載不攜帶 Key。變更 Key 會取消舊查詢並清除舊的聲音顯示資訊，保留已選聲音 ID 與收藏 ID。共享記憶體中繼資料依憑證隔離，不同 Key 的紀錄不會混用。

介面自動跟隨 STranslate 的語言設定，支援简体中文、繁體中文、English、日本語、한국어，沒有獨立的外掛語言選單。介面語言與朗讀文字的語言不同；模型語言支援請查官方文件。

API Key 與透過 ID 輸入框的貼上圖示都位於框內右側，並保留文字空間。API Key 貼上後仍自動儲存；ID 貼上只填入內容，須再按放大鏡或 Enter 查詢，不會直接套用。

聲音 ID 輸入框允許逐步輸入最多 32 個 ASCII 小寫十六進位字元（`0–9`、`a–f`），查詢仍須完整 32 位。無效的鍵入字元不會顯示。Ctrl+V 與框內貼上按鈕都會整次拒絕無效貼上並保留原輸入；不接受大寫字母、空白、URL 或過長內容，也不會自動去除空白、擷取 ID、轉為小寫或截短。

## 搜尋、選擇與試聽聲音

三個入口依序為 **搜尋**、**透過 ID**、**收藏夾**。目前分頁在懸停或按下時仍保留強調色，便於辨識所在面板。已選聲音與搜尋、ID、收藏卡片按 ID 同步套用狀態：未套用顯示勾號，目前套用的 ID 顯示叉號。提示／無障礙名稱為「套用」「清除」，採用一致的無框圖示，保留懸停與鍵盤焦點回饋。按任一匹配卡片的叉號會取消目前聲音；查詢、試聽與收藏不會自動改變選擇。

有選擇時已選卡片始終顯示叉號，搜尋、ID、收藏中的同 ID 卡片亦然。即使同 ID 尚為占位卡片，叉號仍可清除選擇；未套用項的勾號才需等待有效詳情。套用／清除的設定儲存失敗時保留原選擇與卡片狀態。

有聲音 ID 的已選聲音、搜尋結果、透過 ID 結果或收藏夾卡片，都可按標題將該 ID 複製到剪貼簿。成功後顯示浮動提示，失敗則顯示錯誤；作者和描述仍是一般文字，不提供這個複製操作。複製不會套用、試聽或改變收藏。

在 **搜尋** 分頁輸入名稱，按搜尋按鈕或 Enter。修改輸入不會立即查詢，成功提交後才套用新結果並回到第一頁。試聽播放聲音附帶的公開樣本，按勾號（**套用**）使用音色。已選卡片與同 ID 的瀏覽卡片共享試聽狀態；準備時顯示旋轉等待及取消方塊，實際播放後才顯示進度。下載或播放期間再按一次可停止，切換聲音也會停止舊試聽。

搜尋結果首次顯示時展開。數量列右側僅有展開／收合圖示，沒有額外文字標題；圖示切換下方提示、卡片與分頁，數量列始終可見。收合保留查詢、結果、頁碼及選擇；切換分頁或再次搜尋保留目前設定視圖的狀態。編輯頁碼時，先按 Enter 提交或還原，以免失去焦點觸發提交。

搜尋與收藏分頁用無框 `‹` / `›` 圖示，提示／無障礙名稱為「上一頁」「下一頁」，含提示與鍵盤可存取名稱，不顯示文字或矩形按鈕。可輸入頁碼後 Enter／離開輸入框。搜尋每頁六筆原始資料，排除非 TTS 後可能不足六張。`≈` 是近似總數，`?` 是未知，`≤` 是可存取頁數上界。官方窗口可能只開放部分結果；未知上界時僅可到訪問過及允許的下一頁，不自動跳過失敗或空頁。

在 **透過 ID** 輸入完整 32 位小寫十六進位 ID，按放大鏡或 Enter，只查詢一張含試聽、星號與套用狀態圖示的卡片，不改變選擇。未套用須按勾號（**套用**）；已套用 ID 顯示叉號（**清除**），可取消選擇。編輯 ID 或重新查詢移除舊卡片，此入口無分頁／收合。ID 可由[官方社群](https://fish.audio/app/discovery)取得，網站「模型 ID」是聲音資產，不是 `s2.1-pro` 等引擎名。已選或任何匹配卡片的叉號皆可恢復隨機聲音，保留模型、收藏及費用規則。

### 收藏夾

「收藏夾」分頁帶有星號圖示。已選聲音卡片有 ID 時也顯示相同收藏星號，可直接新增或取消；與搜尋、透過 ID 及收藏列表共享同一 ID 集合並同步。新增／取消收藏不改變目前選擇，隨機聲音沒有可收藏的固定 ID。

空心五角星表示尚未收藏，金色實心星表示已收藏；點擊切換，搜尋、透過 ID 與收藏中相同聲音的星號同步。收藏與套用獨立，取消收藏不清除選擇。**收藏夾** 位於 **透過 ID** 右側，只將 ID 依順序存為 JSON 陣列，寫入宿主提供給本外掛的設定目錄中的 `favorite-voices.json`，不將收藏中繼資料寫入主設定，也不與 Fish Audio 帳戶同步。重新啟動後 ID 保留，展示資訊由共享記憶體快取取得，未命中時查詢聲音詳情。

預設空列表，最多 300 個；達上限須先取消一個，不自動淘汰舊收藏。檔案儲存成功後才更新星號及列表，失敗保留原狀。每頁六個，數量及頁數依本機實際收藏計算，可用前後按鈕或輸入頁碼後 Enter／離開輸入框。取消成功後立即移除並更新數量；末頁清空但仍有收藏時移至前一有效頁。收藏夾為空時只顯示空列表提示，不顯示數量、收合圖示或分頁；即使刪除最後一項前已收合，提示也會顯示。儲存錯誤另行提示。詳情未載入時保留占位卡片及取消收藏入口，有效資料載入前無法套用；網路錯誤或找不到聲音不會自動刪除 ID。

收藏夾非空時，數量列右側有獨立的純圖示控制；收合後仍顯示數量，只隱藏提示、卡片及分頁。初次展開，狀態在目前設定視圖內保留，切換分頁或列表更新不重設，也不影響搜尋。編輯頁碼請先提交或還原。搜尋、ID 查詢、收藏與試聽詳情更新共享有界記憶體中繼資料快取，不跨重新啟動儲存，也不是音訊快取。封面沿用共享持久快取，清理不刪收藏 ID。即使快取命中，樣本 URL 仍依下文到期規則檢查。切換收藏頁、取消發起試聽的收藏或替換 ID 結果會停止試聽；遲到結果不會還原收藏或播放。

試聽不呼叫 TTS。可用的樣本 URL 可重複使用，不需要每次重新整理詳情；簽名 URL 進入到期前 30 秒視窗時會更新，簽名時間缺失或無效時也會保守更新。樣本 403/404 最多觸發一次詳情更新及一次重試；先前因到期更新後不再額外更新。不是所有 URL 都有簽名，無簽名也不保證永久有效。無樣本或更新失敗時，不會合成替代音訊。

搜尋、透過 ID 與收藏聲音共用原有的本機封面快取，以聲音 ID 重用宿主提供給本外掛之快取目錄中的 `cover_images` 檔案，收藏不另複製圖片。命中優先顯示本機封面，未命中重新載入並快取。**清理快取** 只刪封面，不刪獨立設定目錄的收藏 ID 檔，也不清空共享聲音中繼資料；清理後，現有卡片改用原始遠端封面位址；後續搜尋、透過 ID 查詢或載入收藏頁時，可再次下載並快取封面。

外掛沒有跨次重用的音訊快取。每次試聽都透過宿主 HTTP 取得樣本，放入本次記憶體緩衝，於停止、結束或失敗後釋放。已選聲音快取只儲存中繼資料及樣本 URL；封面快取只存圖片。試聽進度顯示輸出播放位置，不是下載進度。

共享中繼資料快取最多保留 300 個最近使用項目，客戶端有效期為 15 分鐘，以單調時鐘計算，可跨外掛重新初始化共用，但應用程式重啟後不保留。搜尋與詳情回應更新快取，收藏本身不延長有效期或覆蓋較新資料。樣本 URL 到期或 403/404 會繞過快取重新取得詳情，仍使用一次更新預算；15 分鐘不是 URL 的有效期保證。

<a id="configuration"></a>
## 設定說明

可編輯項目自動儲存。以下為新設定的預設值；舊格式遷移見後文。聲音決定音色，合成模型決定引擎，API Key 驗證帳戶，三者互相獨立。

語速、音量、表現力（Temperature）與多樣性（Top P）都可直接輸入數值：按滑桿右側的數字，會切換為固定大小的輸入框，`dB` 等單位留在框外。離開輸入框或按 Enter 時會驗證並儲存，同步更新滑桿；按 Esc 取消編輯並恢復原值。空白、格式無效、非有限值或超出範圍的輸入會恢復編輯前的值。四項設定統一顯示並儲存兩位小數，拖曳滑桿、滾輪與直接輸入皆採 0.01 精度，例如 Top P 的 `0.82` 與音量 `1.03 dB` 都會保留。

將指標停在滑桿上，或停在尚未按下進入編輯的數值文字上，轉動滾輪即可每格 0.01 微調，至允許的上下限後停止。滑桿軌道、滑塊與數值文字接收此操作，旁邊的單位不在目標範圍；此時滾輪不會捲動設定頁。在滑桿上使用滾輪時，會顯示與拖曳時相同的目前數值氣泡，停止調整片刻或移開指標後消失。按下進入數值輸入框後，在輸入框上捲動不會調值，設定頁依一般方式捲動。

數值編輯只接受 ASCII 數字 `0–9`、最多一個小數分隔符，以及僅音量允許的開頭負號。可使用 `.`；目前區域採小數逗號時也接受 `,`。語速、表現力、Top P 最多 4 個字元、整數一位與小數兩位；音量最多 6 個字元、整數兩位與小數兩位（如 `-10.00`）。不合規則的鍵入不會顯示，無效貼上整體拒絕並保留目前草稿。允許尚未完成的編輯草稿，範圍在確認時檢查。

| 設定 | 預設值 | 選項與作用 |
|---|---|---|
| API Key | 空 | 合成及餘額查詢憑證，可貼上。 |
| 聲音 ID | 空／隨機聲音 | 在搜尋、ID 查詢或收藏卡片按 勾號（**套用**）；空白不代表免費。 |
| 收藏夾 | 空列表 | 獨立檔案僅存有序 ID，最多 300 個，每頁六個；星號新增／取消，不同步帳戶。 |
| 合成模型 | 免費期內 `s2.1-pro-free`，之後 `s2.1-pro` | 清單及預設策略見下文。 |
| 音訊格式 | PCM | PCM / MP3；舊設定通常保留 MP3。 |
| MP3 位元率 | 192 kbps | 64 / 128 / 192；PCM 隱藏整項，切回 MP3 恢復顯示並保留值。 |
| 語速 | 1.0 | 0.5–2.0；拖曳、滾輪與直接輸入皆為 0.01 精度。 |
| 音量 | 0 dB | -10–+10 dB；拖曳、滾輪與直接輸入皆為 0.01 精度；合成音量偏移，不是靜音開關。 |
| 響度歸一化 | 開啟 | 支援 S2 系列模型；僅三項白名單顯示並傳送，其他模型隱藏但保留值。 |
| 表現力 | 0.7 | 0–1；拖曳、滾輪與直接輸入皆為 0.01 精度；越高越多樣，越低一致性越強。 |
| 多樣性 | 0.7 | 外掛允許 0.05–1；拖曳、滾輪與直接輸入皆為 0.01 精度；Top P 取樣控制。 |
| 延遲模式 | 品質優先（`normal`） | 品質優先／平衡（`balanced`）／低延遲（`low`），不保證固定首字時間。 |
| 文字規範化 | 關閉 | 將數字、單位等轉為適合朗讀的文字。 |
| 上下文關聯 | 開啟 | 使用本次合成的前序片段，不引用以前產生的其他音訊。 |
| 餘額重新整理 | 啟動靜默嘗試 | 手動更新顯示延遲；朗讀成功後靜默更新，不是消費上限。 |
| 封面快取 | 自動使用 | 顯示磁碟佔用及 **清理快取**；保留聲音 ID、資料及收藏。 |
| 免費推廣卡 | 尚未關閉 | 點擊選擇免費模型，關閉後記住隱藏，不會改變資格。 |
| 介面語言 | 跟隨宿主 | 五種語言自動切換，無獨立選項。 |

響度歸一化只對 `s2.1-pro-free`、`s2.1-pro`、`s2-pro` 顯示並傳送 `normalize_loudness`。S1 下參數不生效；Drama 3 支援尚未確認，因此依目前客戶端能力策略隱藏，不表示已證實服務端不支援。隱藏保留原值並省略請求欄位，切回白名單後恢復。

**2026-12-01T00:00:00Z 之前**的順序為 `s2.1-pro-free`、`drama-3`、`s2.1-pro`、`s2-pro`、`s1`，預設免費模型。到期後隱藏免費項，其餘清單以 Drama 3 開頭，但預設仍為 `s2.1-pro`。清單第一項不等於預設；有效的已存選擇不因重排改變，無法使用的選擇按當時預設規則修正。活動以[官方條件](https://fish.audio/blog/s2-1-pro-free-api/)為準。

目前仍可選 S1；[官方 WS 文件](https://docs.fish.audio/api-reference/endpoint/websocket/tts-live)公告其於 2026-12-31 退役，之後指定 S1 的請求由 S2.1-Pro 服務。接近該日期請確認官方計費及外掛更新，不要假設舊選擇永久保持原服務。

主設定版本為 SchemaVersion=2，升級保留有效欄位。無版本／版本 1 的缺失或無效音訊格式回落 MP3，保留有效位元率，新設定預設 PCM。收藏 ID 使用獨立檔案，不是主設定中的中繼資料欄位，也不增加設定版本。格式切換保留其他參數與隱藏的 MP3 位元率，模型切換保留隱藏的響度值。載入設定時，無效數值回復預設；有效值依顯示小數位數保留，不對齊滑桿間距。未來／重複版本標記保護主設定檔，請勿手動降低版本強制儲存。

舊版串流代理模式與位址不再生效，受支援設定的標準化儲存會移除舊欄位，版本仍為 2。

Top P 的 0.05 下限是外掛相容策略，不是官方 API 最小值宣告。舊設定 0 提升為 0.05；負值、非有限值或大於 1 的值回復 0.7。表現力（Temperature）的 0 仍有效，範圍維持 0–1。

<a id="audio-formats"></a>
## PCM 與 MP3

PCM 採用 44.1 kHz、16 位元、單聲道，不需要壓縮解碼，約每秒 88,200 位元組。MP3 持續解碼，64/128/192 kbps 可降低傳輸量；較高位元率需要更多頻寬。慢速連線可試 MP3，減少壓縮處理可用 PCM。伺服器排隊、網路、裝置緩衝與初始靜音都影響啟播，任何格式都不保證固定首字延遲。

長文按需分段傳送，同時接收播放音訊，不等整段下載。一般文字可提早啟播；複雜或未閉合的情緒／發音標記可能延後安全分段。外掛保留文字順序，但不是完整標記編輯器；模型語法請查[官方文件](https://docs.fish.audio)。目前不提供 WAV/Opus 選項。

<a id="network-and-proxy"></a>
## 網路與系統連線

正式朗讀使用原生 WebSocket，固定採用系統預設代理；外掛沒有獨立代理開關、模式或位址設定。聲音搜尋、詳情、餘額及試聽樣本仍使用 STranslate 宿主 HTTP 網路設定，兩條路徑需分別可用。宿主 HTTP 成功不代表系統 WebSocket 已連通。

中國大陸網路無法存取 `fish.audio` 時，請檢查 Windows 系統網路／代理、代理程式是否可用及防火牆是否允許 WebSocket，不需要在外掛尋找代理輸入。搜尋可用但朗讀失敗時，核對系統連線、模型及帳戶權限；修復後手動重試，外掛不自動換模型或再次合成。

<a id="playback-and-cost"></a>
## 朗讀、停止與費用

透過 STranslate 的朗讀功能使用外掛。新朗讀會取消舊會話並等候輸出清理；宿主停止、初始化週期結束或關閉也會取消播放。執行中的請求使用啟動快照，之後修改下次生效。正常結束會等已收到的真實音訊播放完畢。

取消只停止客戶端，不保證服務端沒有生成或計費。斷線、逾時及解碼錯誤不會自動再次合成，也不會失敗後改用付費模型、HTTP 或其他傳輸。到期模型可能在啟動時修正為當時預設項，因此更新／活動到期後須再核對。

嚴格零費用時，僅在目前官方條件確認資格、並明確選擇 `s2.1-pro-free` 後才合成。無法確認時只使用搜尋與試聽，不發出真實合成。隨機聲音、格式正確的 Key、未變動餘額或名稱含 free 不能單獨證明免費。付費模型需餘額，扣款可能延遲；外掛沒有消費硬上限。免費服務也無固定首音延遲保證。

<a id="troubleshooting"></a>
## 問題排解

| 現象 | 檢查與處理 |
|---|---|
| 響度項消失或舊 Top P 變成 0.05 | 響度依客戶端白名單隱藏但保留值；Top P 舊 0 提升至相容下限，Temperature 的 0 不變。 |
| Key 格式錯誤 | 從官方重複製，移除空白／換行；不要混用 Key 與聲音 ID。 |
| 搜尋可用但朗讀失敗 | 分別檢查宿主 HTTP、系統 WebSocket 網路、模型及帳戶權限。 |
| 總數很大卻無下一頁 | 可能受官方視窗限制，改用更精確名稱。 |
| 收合後看不到卡片 | 展開結果即可，查詢／頁碼／選擇仍保留。 |
| ID 查到聲音卻未改變選擇 | 按結果卡片的勾號（**套用**）；查詢、試聽或星號不會自動套用。 |
| 無法新增收藏或僅有占位 | 檢查 300 個上限、檔案儲存提示及聲音詳情網路；載入失敗不刪 ID，仍可取消收藏。 |
| 試聽不可用或失敗 | 檢查宿主網路；可能無樣本或 URL 過期，重新查詢詳情。不會以 TTS 取代。 |
| 首次播放很慢 | 檢查系統網路與裝置，可比較 PCM/MP3；免費佇列仍可能影響速度。 |
| 無聲或中斷 | 檢查 Windows 輸出、系統／應用程式音量及裝置連線，修正後手動重試。 |
| 餘額未立即變化 | 等候後手動更新，舊餘額不是免費證據。 |
| 清理後重載封面 | 正常行為，清理只刪圖片，保留聲音設定與收藏。 |

仍有問題可在 [Issues](https://github.com/Cirnouo/STranslate.Plugin.Tts.FishAudio/issues) 提供外掛／宿主／Windows 版本、重現步驟、模型／格式及系統網路情況與去識別化錯誤。不要上傳金鑰、完整簽名 URL、代理密碼或私人文字。開發請見 [CONTRIBUTING](../../CONTRIBUTING.md)。
