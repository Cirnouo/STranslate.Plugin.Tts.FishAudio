# DD-010: Random voice when VoiceId is empty

**Status:** Current.

**Recorded:** 2026-04-27.

**Current interpretation:** Empty VoiceId omits reference_id from the formal TTS body. The selected-voice display uses the localized Random Voice label. This fallback is not an assertion of zero billing.

**Migration review:** The approximate deduction delay in the original context is a historical provider observation. It is not a timing guarantee or evidence of a free request.

## Recorded rationale

The original rationale below is retained for traceability; where a migration review narrows it, the current interpretation and linked successor take precedence.

**Context:** When no `reference_id` is sent in the TTS request, Fish Audio uses a random/default voice. This still costs credit (deducted asynchronously, ~60s delay).
**Decision:** When `VoiceId` is empty, show a localized "Random Voice" title in the display area instead of blank. `FishAudioApi.PostTtsAsync` omits `reference_id` from the body entirely (does not send empty string).
**Affects:** `SettingsViewModel.ApplyCachedVoice()`, `FishAudioApi.PostTtsAsync()`.
