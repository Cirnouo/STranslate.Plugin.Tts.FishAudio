# DD-005: Auto-save on property change

**Status:** Current.

**Recorded:** 2026-04-27 (extended 2026-06-26).

**Amended or extended by:** [DD-038](../current/DD-038.md), [DD-039](../current/DD-039.md).

**Current interpretation:** Editable settings, including the API Key, save on property change through SettingsStore. Production writes use the captured settings write lease; a retired ViewModel does not perform a final save.

**Migration review:** The original direct SaveSettingStorage wording predates SettingsStore and write leases. The current interpretation above is authoritative for the persistence route.

## Recorded rationale

The original rationale below is retained for traceability; where a migration review narrows it, the current interpretation and linked successor take precedence.

**Context:** Users expect slider, toggle, and text setting changes to persist immediately without a "Save" button. API Key no longer has a separate confirm/apply lifecycle (see [DD-030](../current/DD-030.md)).
**Decision:** `OnPropertyChanged` writes settings properties, including `ApiKey`, to `_settings` and calls `SaveSettingStorage` immediately.
**Affects:** `SettingsViewModel.OnPropertyChanged()`.
