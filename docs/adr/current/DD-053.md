# DD-053: Preserve MP3 compatibility and make native streaming routing explicit

**Status:** Current.

**Recorded:** 2026-10-20.

**Amends:** [DD-009](DD-009.md), [DD-031](DD-031.md), [DD-038](DD-038.md), [DD-041](DD-041.md). [DD-045](DD-045.md) retains the free cutoff.

## Context

PCM avoids compressed decoder startup but increases transfer volume; it is a useful new default, not a universal end-to-end speed guarantee. Existing users already express MP3 bitrate preferences. Host HTTP routing does not automatically configure a native socket. Adding Drama 3 must not change the intended post-promotion default.

## Decision

Advance settings to schema 2. New/current configurations default to PCM; schema 0/1 migrates with MP3 fallback and retains valid bitrate. Preserve explicit supported format, field precedence, canonical saves, transaction rollback and future/duplicate-schema read-only protection. Keep bitrate while PCM is selected and send it only for MP3. Current UI hides the entire bitrate card for PCM and restores it for MP3; the stored bitrate survives both transitions.

The original decision exposed system/direct/custom native proxy settings. That portion is superseded by [DD-055](DD-055.md): native streaming now always uses the system proxy and exposes no proxy settings. Metadata, credit and preview retain host HTTP. Keep request snapshots private without generated record value printing; never log settings or raw exceptions. The original distinction between native and host HTTP ownership remains relevant, but it does not require an editable plugin proxy.

Order models free, Drama 3, S2.1-Pro, S2-Pro, S1 before exclusive `2026-12-01T00:00:00Z`, omitting only free afterward. Default remains free before and S2.1-Pro after, independently of list position. Preserve valid saved selections. Omit normalize_loudness and hide its complete card for Drama 3 and S1, preserving the stored value. Official sources establish no effect on S1 and leave Drama 3 unconfirmed; the three-model whitelist is an explicit client capability policy. No paid Drama 3 real test is asserted.

Keep S1 in the locked current list. The [official native WS page](https://docs.fish.audio/api-reference/endpoint/websocket/tts-live), verified 2026-10-20, says it retires December 31, 2026 and is then served by S2.1-Pro. Record this future maintenance fact without inventing a client migration or server guarantee.

## Consequences and implementation basis

Upgrades retain MP3 intent; new users get PCM. Native routing can differ from REST routing. Removed proxy fields cannot influence current requests; follow DD-055 for compatibility cleanup. Application dates/defaults do not authorize billable live tests.
