# DD-053: Preserve MP3 compatibility and make native streaming routing explicit

**Status:** Current.

**Recorded:** 2026-10-20.

**Amends:** [DD-009](DD-009.md), [DD-031](DD-031.md), [DD-038](DD-038.md), [DD-041](DD-041.md). [DD-045](DD-045.md) retains the free cutoff.

## Context

PCM avoids compressed decoder startup but increases transfer volume; it is a useful new default, not a universal end-to-end speed guarantee. Existing users already express MP3 bitrate preferences. Host HTTP routing does not automatically configure a native socket.

## Decision

Advance settings to schema 2. New/current configurations default to PCM; schema 0/1 migrates with MP3 fallback and retains valid bitrate. Preserve explicit supported format, field precedence, canonical saves, transaction rollback and future/duplicate-schema read-only protection. Keep bitrate while PCM is selected, enable its UI and send it only for MP3.

Expose system/direct/custom native streaming proxy settings. System uses .NET's default proxy, direct bypasses it, custom requires validated HTTP/HTTPS/SOCKS5 host and explicit port. Preserve invalid custom input and block connect with localized feedback. Remove credentials from the transport URI and set them separately. Metadata, credit and preview retain host HTTP. Capture private values in a class without generated record value printing; never log settings or raw exceptions.

Order models free, S2.1-Pro, S2-Pro, S1 before exclusive `2026-12-01T00:00:00Z`, omitting only free afterward. Default remains free before and S2.1-Pro after, independently of list position. Preserve valid saved selections. Omit normalize_loudness and disable its visible control for S1.

Keep S1 in the locked current list. The [official native WS page](https://docs.fish.audio/api-reference/endpoint/websocket/tts-live), verified 2026-10-20, says it retires December 31, 2026 and is then served by S2.1-Pro. Record this future maintenance fact without inventing a client migration or server guarantee.

## Consequences and implementation basis

Upgrades retain MP3 intent; new users get PCM. Native routing can differ from REST routing. Proxy credentials remain sensitive stored/request data. Application dates/defaults do not authorize billable live tests.
