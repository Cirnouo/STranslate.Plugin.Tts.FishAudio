# DD-045: Free model availability is extended through November 2026

**Status:** Current.

**Recorded:** 2026-09-01.

**Supersedes or replaces part of:** [DD-036](../history/DD-036.md).

**Current interpretation:** Runtime policy uses the exclusive cutoff 2026-12-01T00:00:00Z and retains the free model through 2026-11-30 UTC. This documents current application policy, not independent proof of provider billing eligibility.

**Migration review:** Provider promotion eligibility must be rechecked under the evidence policy before any real synthesis. The stored runtime cutoff is not a spending authorization.

## Recorded rationale

The original rationale below is retained for traceability; where a migration review narrows it, the current interpretation and linked successor take precedence.

**Context:** Fish Audio extended the `s2.1-pro-free` promotion beyond the August 31 deadline recorded by [DD-036](../history/DD-036.md) through the full UTC day of November 30. The centralized runtime cutoff, five localized model descriptions, README files, API notes, and release metadata must move together so the plugin neither hides an available model nor advertises it after expiry.
**Decision:** Keep the cutoff centralized in `Configuration/FishAudioModelPolicy` and move it to `2026-12-01T00:00:00Z`. Every instant before the cutoff, including the final tick of `2026-11-30` UTC, retains `s2.1-pro-free` in the available model list and uses it as the default; at and after the cutoff the plugin hides it and defaults to `s2.1-pro`. README tips state the concise November 30 calendar date, while model tables, localized model descriptions, and API documentation retain the exact UTC boundary. [DD-036](../history/DD-036.md) remains historical and is superseded only for the cutoff date.
**Affects:** `Configuration/FishAudioModelPolicy`, language resources, README files, `docs/api-tts.md`, changelog, regression tests.
