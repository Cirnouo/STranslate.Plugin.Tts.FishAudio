# Voice browsing, preview and cover cache

Status: current implementation. Browsing and preview do not require the user's synthesis API Key. [VoiceDiscoveryCoordinator](../../STranslate.Plugin.Tts.FishAudio/Presentation/VoiceDiscoveryCoordinator.cs) uses the `dummy` bearer token for `/model` and `/model/{id}`, with 15-second request timeouts. By-ID lookup validates Voice ID shape before HTTP and rejects explicit non-TTS types; missing/blank type remains compatible with old responses. Only a model-detail 404 maps to not-found; other failures remain distinguishable request errors.

## Search and pagination

Search is explicit through its button or Enter, with pages of six raw records, `sort_by=score` and an escaped title filter. New successful queries reset to page one. Page input supports Enter/LostFocus and numeric typing; boundary buttons hide without moving the center control. Applied results, pagination and query change together; an unsubmitted input edit does not affect a later page request. Failed, replaced or disposed operations cannot publish late results.

[VoiceSearchPagination](../../STranslate.Plugin.Tts.FishAudio/Presentation/VoiceSearchPagination.cs) keeps reported total, exactness, last accessible page and Next availability separate. `max_offset` restricts starting offsets; `accessible_upper_bound` limits accessible records. Precise `total` can add a bound; approximate `total` cannot authorize jumps. The minimum applicable bound still permits a partial final page, such as page 167 at offset 996 under a 1000-record window. Window limitation can be inferred when a hard bound truncates an exact total, even if the flag is missing.

An explicit `has_more=false` or empty raw items stops forward navigation. Raw full pages without any total/metadata allow one further attempt; raw short pages stop unless the server explicitly permits more. Without a known bound, only visited pages and the currently permitted next page are reachable. Empty pages are not automatically retried or skipped. Raw record counts govern paging before explicit non-TTS records are filtered from selectable cards.

Pagination is published before cover resolution. The stable numeric facade properties remain, but navigation follows the applied policy rather than an editable presentation value. UI uses `≈` for approximate counts, `?` for unknowns and `≤` for accessible page bounds; all five locales explain the window. Exact provider window-edge semantics have not been live-tested at every offset; see [DD-048](../adr/current/DD-048.md).

Search, by-ID lookup and startup selected-voice refresh reject late results after replacement, selection changes or disposal. Selected metadata is cached with the settings; search results remain observable independent objects. Preview state is keyed by Voice ID so the selected card and matching search result show the same stop/progress state.

[PreviewAudioUrlPolicy](../../STranslate.Plugin.Tts.FishAudio/Presentation/PreviewAudioUrlPolicy.cs) allows only HTTPS platform.r2.fish.audio and non-empty subdomains of r2.cloudflarestorage.com. It evaluates case-insensitive X-Amz-Date/X-Amz-Expires. Unsigned allowed URLs are reusable; signed URLs refresh thirty seconds before expiry. Missing/duplicate/malformed/overflowing signed timing requires conservative refresh.

[PreviewRefreshCoordinator](../../STranslate.Plugin.Tts.FishAudio/Presentation/PreviewRefreshCoordinator.cs) handles both entry points. Inside the refresh window it fetches fresh detail using dummy. Selected refresh saves complete current CachedVoice metadata; search refresh updates that result and does not save settings. A response without a usable sample is authoritative. Refresh failure never falls back to an already-expiring URL. Repeated stop/pending clicks avoid a new network request; target changes and Dispose invalidate pending work.

[PreviewPlaybackController](../../STranslate.Plugin.Tts.FishAudio/Presentation/PreviewPlaybackController.cs) still opens the remote sample URI directly in WPF MediaPlayer. It plays at client volume 1.0, updates progress on a 50 ms DispatcherTimer after MediaOpened, and stops/disposes on end or media failure. There is currently no bounded host-HTTP preview audio download or memory-backed preview player. The remote media fetch does not go through the plugin's IHttpService, so metadata request success does not prove this media path uses the same proxy or can play. This is an implementation limitation, not a proven root cause for every preview failure.

[CoverImageCacheService](../../STranslate.Plugin.Tts.FishAudio/Caching/CoverImageCacheService.cs) stores `cover_images/<voiceId>.jpg` under the host cache directory. A local hit wins; a miss displays CDN content and downloads in the background. A ten-second token and 256 KiB + 1 read bound limit downloads. Only non-empty JPEG/PNG/GIF/WebP-looking content up to 256 KiB is cached. Cache usage rescans actual JPG files. Cleanup is scoped to cover_images, exposes busy state, recovers its button after ten seconds and prevents a late old task from unlocking a newer operation.
