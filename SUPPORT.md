# Support

Start with the [project overview](README.md) and the detailed user guide in your preferred language: [简体中文](docs/user-guide/README.md), [繁體中文](docs/user-guide/README.zh-TW.md), [English](docs/user-guide/README.en.md), [日本語](docs/user-guide/README.ja.md) or [한국어](docs/user-guide/README.ko.md).

Search [existing issues](https://github.com/Cirnouo/STranslate.Plugin.Tts.FishAudio/issues) before opening a [bug report or feature request](https://github.com/Cirnouo/STranslate.Plugin.Tts.FishAudio/issues/new/choose). For a question that does not fit a form, use a blank issue. State your plugin, STranslate and Windows versions, what you tried, what you expected and what happened. For audio problems, identify whether search, preview or formal speech is affected, along with the model, audio format and relevant output-device or network conditions.

Only post diagnostics you have inspected and sanitized. Remove API keys, Authorization headers, proxy credentials, account identifiers, private synthesis text and full signed URLs. Do not attach your complete settings file. You do not need to purchase synthesis or reproduce an expensive request merely to ask for help.

For a suspected security vulnerability, follow [SECURITY.md](SECURITY.md) and keep details out of public issues. Community participation follows the [code of conduct](CODE_OF_CONDUCT.md). To contribute a change, read [CONTRIBUTING.md](CONTRIBUTING.md).

This repository handles the plugin. Account, billing and service questions belong to [Fish Audio](https://fish.audio/); host application issues belong to [STranslate](https://github.com/STranslate/STranslate). Support here is provided through repository participation, without a guaranteed response time or service-level agreement.
