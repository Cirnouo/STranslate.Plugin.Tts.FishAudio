# Security policy

Report suspected vulnerabilities in this plugin through [GitHub private vulnerability reporting](https://github.com/Cirnouo/STranslate.Plugin.Tts.FishAudio/security/advisories/new). This sends a private report to the repository maintainers. Do not publish vulnerability details in an issue, pull request, screenshot or public log.

Include the affected plugin version or commit, STranslate and Windows versions, a description of the security impact, and the smallest reproduction you can share safely. Explain the prerequisites and what an attacker could do. Use test data and redact API keys, Authorization headers, account identifiers, proxy credentials, private synthesis text and signed media URLs. Do not access another person's account or data to demonstrate a problem.

If GitHub's private reporting form is unavailable, open an issue asking maintainers for a secure reporting method without including vulnerability details or private information. No separate security email address is published by this project.

Use the [support guide](SUPPORT.md) for installation questions and ordinary bugs. Problems in STranslate itself or Fish Audio's service should be reported through those projects' own reporting channels; describe any plugin-specific impact here without exposing credentials.

Reports are assessed against the affected code and release. This policy does not promise a response deadline, fix date or maintained-version matrix. Coordinate any public disclosure with the maintainers so that sensitive reproduction details are handled deliberately.
